# 数据结构与算法实践 · 前言

## 这本书写给谁

本书面向高中阶段已经学过一门编程语言基础语法的读者。所谓“学过基础语法”，指的是你能读懂变量、条件、循环、函数和列表，能自己写出把一串数字求和的程序。本书不要求你有竞赛经历，也不要求提前学过数据结构。讲解方式与初中不同：初中告诉你“这样做能跑通”，本书会追问“为什么要这样做、代价是什么、什么情况下不能用”。

## 先修要求

开始之前，请确认你能独立完成下面几件事。

- 用 Python 定义函数，接收参数并返回值。
- 用循环遍历列表，做累加或计数。
- 理解列表索引从 0 开始，会用切片。
- 知道字典用来建立“键到值”的对应关系。
- 能读懂报错信息并修好缩进错误。

示例代码只用 Python 3.12 标准库，不需要第三方包、联网、账号或付费服务。数据量都很小，直接写在代码里，你可以抄下来运行并核对输出。

## 学习路径

第一章解决一个看似抽象但贯穿全书的问题：怎样比较两个算法的快慢。你会学到用输入规模的函数描述运行时间，认识常数级、对数级、线性级、平方级几种增长方式。

第二章和第三章处理最基础的两类容器：数组（及其变体字符串）和栈、队列。同一个需求用不同容器实现，代价差别可能很大。

第四、五、六三章是全书中段支柱：字典与集合、搜索、排序。排序一章同时展示三种思路不同的算法，让你看到“平均表现好”和“最坏情况下有保证”之间的取舍。

第七章的递归与第八章的树联系紧密：树的遍历天然用递归表达，递归的代价又需要用树的形状理解。第九章的图把树推广开来。第十、十一章的贪心和动态规划是两种设计策略，难点常在“怎样把它拆成可重复利用的小问题”。第十二章是综合项目，要求你实际使用前面十一章的知识。

## 每一章怎么用

每一章顺序相同：学习目标、开始之前、情景导入、知识讲解、详细示例、动手实践、常见误区、练习与自测、本章小结、延伸阅读。

知识讲解通常分四到五个小节，每节先说明这个工具解决什么问题，再说明它内部怎么工作，最后说明什么条件下会失效。详细示例完整展开推理过程，包括走过的弯路。动手实践给出至少六个步骤和明确的完成判据。

常见误区一节值得单独留意，比如“复杂度低的算法在任何情况下都更快”“递归总是比循环慢”，这些说法都有反例。

## 本书的综合项目

最后一章要求你完成一个综合项目：为校园场景设计并实现一套小型查询与统计工具，用到数组、字典、排序、搜索，并处理边界输入和说明复杂度。

## 需要注意的边界

本书由 AI 辅助原创编写，未经过教师人工审校。推导和程序输出经过实际运行核对，但编排顺序和练习难度没有在真实课堂上验证过。来源链接是官方文档或权威机构页面，不代表本书内容经过这些机构认可。不要把“这个算法更快”当成放之四海而皆准的定律，每一章的复杂度分析都附带了前提条件。
