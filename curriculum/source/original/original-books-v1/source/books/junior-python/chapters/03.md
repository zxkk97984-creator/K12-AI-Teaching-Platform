# 处理文本：字符串

## 学习目标

- 用索引和切片取出字符串的一部分
- 用常用方法处理文本
- 用格式化把变量嵌入文本

## 开始之前

上一章我们把文字存进了字符串。这一章要学的是怎么处理它——取出其中一部分、改大小写、拆分、拼装。

先想一想这个问题：如果要你从"张三,李四,王五"这一串里分别取出三个名字，你会怎么做？如果人数变成二十个，你还会用同样的办法吗？

材料：一台能运行 Python 的电脑；纸和笔。

## 知识讲解

### 字符串和索引

字符串是一串字符。它可以像架子上的格子一样编号，每个位置放一个字符。

编号从 0 开始，这一点初学者最容易记错。比如：

```python
s = "python"
print(s[0])
print(s[1])
print(s[5])
```

输出是 `p`、`y`、`n`。为什么 `s[5]` 是 `n`？因为 `"python"` 有 6 个字符，编号是 0 到 5：`p` 是 0，`y` 是 1，`t` 是 2，`h` 是 3，`o` 是 4，`n` 是 5。

**从 0 开始编号**这件事要多念几遍。它带来一个常见错误：访问 `s[6]` 会报错，因为 `"python"` 没有第 6 号位置。这个错误叫"索引超出范围"。

Python 还支持用负数从后往前数：

```python
print(s[-1])
print(s[-2])
```

输出是 `n` 和 `o`。`s[-1]` 是最后一个字符，`s[-2]` 是倒数第二个。这个写法很实用，因为你不用先算长度。

想知道字符串有多长，用 `len()`：

```python
print(len("python"))
```

输出 `6`。注意长度是 6，但最大的编号是 5。这个"差一"的关系要记牢：**长度是 n 的字符串，编号从 0 到 n-1**。

### 切片

切片是从字符串里取出一段连续的部分。写法是用冒号隔开起止位置：

```python
s = "python"
print(s[1:4])
```

输出 `yth`。为什么？`[1:4]` 的意思是"从编号 1 开始，取到编号 4 之前为止"，也就是取编号 1、2、3 这三个字符，不包含编号 4。这个规则叫"含头不含尾"，是切片最容易出错的地方。

几个常用的简写：

```python
print(s[:3])
print(s[3:])
print(s[:])
```

`s[:3]` 是从头取到编号 3 之前，得到 `pyt`。`s[3:]` 是从编号 3 取到最后，得到 `hon`。`s[:]` 是全部。

切片还有一个好处：**它不会因为超出范围而报错**。

```python
print(s[2:100])
```

会输出 `thon`，而不是报错。因为"取到编号 100 之前"这个要求，在字符串结束的地方就自然停了。这一点和索引不同——`s[100]` 会报错，但 `s[2:100]` 不会。所以在不确定字符串长度的时候，用切片比用索引安全。

切片还可以加步长，第三个数字表示每隔几个取一个：

```python
print(s[0:6:2])
```

输出 `pto`，因为从编号 0 开始，每隔 2 个取一个：0 号 `p`、2 号 `t`、4 号 `o`。用 `s[::-1]` 可以把字符串倒过来，得到 `nohtyp`。

### 常用方法

方法是一种"附在某个东西上的功能"，写法是"东西点方法名"。字符串有一批很常用的方法。

**改变大小写。**

```python
print("Python".upper())
print("Python".lower())
```

输出 `PYTHON` 和 `python`。这两个在处理用户输入时很有用，因为用户可能大小写混着输。

**去掉两端的空白。**

```python
print("  hi  ".strip())
```

输出 `hi`。`strip()` 去掉两端的空格、换行符等。这个在读取文件或接收输入时特别重要，因为读进来的文字常常带着多余的换行符。它还有两个变体：`lstrip()` 只去左边，`rstrip()` 只去右边。

**替换。**

```python
print("a-b-c".replace("-", "+"))
```

输出 `a+b+c`。第一个参数是要被替换掉的，第二个是替换成什么。

**拆分和连接。**

```python
parts = "小雨,小北,小然".split(",")
print(parts)
print(len(parts))
```

输出是 `['小雨', '小北', '小然']` 和 `3`。`split(",")` 按逗号把字符串切开，得到一个列表（列表在第六章会详细讲）。

反过来的操作是 `join`，注意它的写法比较特别——分隔符写在前面：

```python
print("-".join(["a", "b", "c"]))
```

输出 `a-b-c`。

**查找和判断。**

```python
print("hello".find("l"))
print("hello".find("z"))
print("hello".startswith("he"))
print("123".isdigit())
```

输出是 `2`、`-1`、`True`、`True`。`find` 返回第一次出现的位置，找不到返回 `-1`（不是报错，这一点要注意）。`startswith` 判断是不是以某段开头。`isdigit` 判断是不是全部由数字组成——这个在检查输入是否合法时很有用。

有一个重要的提醒：**字符串的方法不会改变原来的字符串，而是返回一个新的**。

```python
s = "Hello"
s.lower()
print(s)
```

输出还是 `Hello`。因为 `lower()` 只是返回了一个新的小写字符串，没有改 `s` 本身。要得到小写的结果，得写 `s = s.lower()`。这个特点和列表不同，列表的有些方法会直接改掉自己，第六章会讲到。

### 格式化输出

把变量嵌进文字里，有三种常用写法。

**第一种：用加号拼接。**

```python
name = "小雨"
age = 12
print("我叫" + name + "，今年" + str(age) + "岁")
```

能work，但很啰嗦，而且必须记得用 `str()` 转换数字，否则报错。

**第二种：用格式化字符串（推荐）。**

```python
print(f"我叫{name}，今年{age}岁")
```

在引号前面加一个 `f`，然后把变量名写在花括号里。它会自动把变量转成文字，不用写 `str()`。这种写法叫 f-string，是目前最常用也最好读的写法。

f-string 的花括号里还可以直接写计算：

```python
price = 35
count = 3
print(f"总价是 {price * count} 元")
```

输出 `总价是 105 元`。

**第三种：用 `format` 方法。**

```python
print("我叫{}，今年{}岁".format(name, age))
```

花括号里按顺序填入后面的参数。这种写法在老代码里常见。

f-string 还能控制小数位数，这在算钱或者算平均分时很有用：

```python
score = 87.33333333333333
print(f"平均分是 {score:.2f}")
```

输出 `平均分是 87.33`。`:.2f` 的意思是"保留两位小数"。如果不写这个，就会把一长串小数全打出来，很难看。

## 详细示例

### 示例一：处理一行名单

**问题**：给定一行名单 `"小雨,小北,小然,小林,小方"`，请写程序完成三件事：第一，输出一共有几个人；第二，把每个人的名字单独输出一行，并且加上编号（从 1 开始）；第三，输出每个人的名字有几个字。

**材料**：Python 环境；纸和笔。

**逐步推理**：

第一步，先把名单存进变量：

```python
roster = "小雨,小北,小然,小林,小方"
```

第二步，用 `split` 按逗号切开：

```python
names = roster.split(",")
```

现在 `names` 是一个列表，里面是五个名字。

第三步，算人数。列表的长度就是人数：

```python
print(f"一共 {len(names)} 个人")
```

第四步，按编号输出每个人。这里需要一个循环（第五章会详细讲），现在先照写：

```python
for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")
```

`enumerate` 的作用是一边遍历一边给出序号，`start=1` 表示从 1 开始编号。

第五步，输出每个人名字的字数。用 `len()` 量：

```python
for name in names:
    print(f"{name} 有 {len(name)} 个字")
```

第六步，把程序连起来运行：

```python
roster = "小雨,小北,小然,小林,小方"
names = roster.split(",")

print(f"一共 {len(names)} 个人")
for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")
for name in names:
    print(f"{name} 有 {len(name)} 个字")
```

输出：

```text
一共 5 个人
1. 小雨
2. 小北
3. 小然
4. 小林
5. 小方
小雨 有 2 个字
小北 有 2 个字
小然 有 2 个字
小林 有 2 个字
小方 有 2 个字
```

**结果**：程序正确输出了人数、带编号的名单，以及每个名字的字数。

**为什么正确**：我们抓住了这串文字的规律——人名之间用逗号隔开，所以用 `split(",")` 就能切开。切开以后不管有多少人，程序都一样能处理，因为人数是由 `len(names)` 算出来的，而不是写死的。

**一个边界情况**：如果名单里有多余的空格呢？比如 `"小雨, 小北, 小然"`（逗号后面有空格）。这时 `split(",")` 切出来的第二段是 `" 小北"`，前面带一个空格。显示出来可能看不出问题，但如果后面要比较两个名字是不是同一个，就会出错。处理办法有两种：一是切开以后对每一段用 `strip()` 去掉空格；二是用 `split()` 不传参数，它会自动把连续的空格和逗号都当作分隔符处理。第二种更省事，但它对"逗号加空格"和"只有逗号"的处理是一样的，具体用哪种要看数据的实际情况。

### 示例二：从一行记录里提取信息

**问题**：学校把每个学生的信息记成一行文字，格式是"姓名|学号|班级"，比如 `"小雨|20260301|初一三班"`。请写程序把这三部分分别提取出来并输出。

**材料**：上面的格式说明；Python 环境。

**逐步推理**：

第一步，把记录存进变量：

```python
record = "小雨|20260301|初一三班"
```

第二步，按竖线切开：

```python
fields = record.split("|")
print(fields)
```

输出 `['小雨', '20260301', '初一三班']`。

第三步，把三个部分分别取出来。可以用索引，也可以用"解包"（一次把列表里的几项分给几个变量）：

```python
name, student_id, class_name = fields
```

这一行的意思是：把 `fields` 里的三项依次分给这三个变量。它要求两边的数量必须一致，否则报错。

第四步，输出：

```python
print(f"姓名：{name}")
print(f"学号：{student_id}")
print(f"班级：{class_name}")
```

第五步，加上一个检查。学号应该全是数字，可以用 `isdigit()` 验证：

```python
if student_id.isdigit():
    print("学号格式正确")
else:
    print("学号格式有问题")
```

第六步，完整程序：

```python
record = "小雨|20260301|初一三班"
fields = record.split("|")

print(fields)
name, student_id, class_name = fields

print(f"姓名：{name}")
print(f"学号：{student_id}")
print(f"班级：{class_name}")

if student_id.isdigit():
    print("学号格式正确")
else:
    print("学号格式有问题")
```

输出：

```text
['小雨', '20260301', '初一三班']
姓名：小雨
学号：20260301
班级：初一三班
学号格式正确
```

**结果**：三部分信息都被正确提取出来，并且学号通过了格式检查。

**为什么正确**：我们用了一个明确的分隔符 `|` 来切分。选分隔符的原则是"它不能出现在正常的内容里"——姓名、学号、班级名里都不会有竖线，所以用它做分隔是安全的。如果用空格或者逗号，就可能和内容本身冲突。

**一个边界情况**：如果某一行记录少了字段呢？比如 `"小雨|20260301"` 只有两段。这时 `name, student_id, class_name = fields` 会报错，说"没有足够的值可以解包"。这类问题在实际处理数据时很常见，因为数据往往不干净。稳妥的做法是先检查字段数量：

```python
if len(fields) == 3:
    name, student_id, class_name = fields
else:
    print(f"这一行格式不对，只有 {len(fields)} 个字段")
```

这样程序遇到坏数据时不会直接崩掉，而是会告诉你哪里有问题。这个习惯在处理真实数据时非常重要。

## 动手实践

**目标**：写一个程序，对一段文字做多种处理，并输出整理后的结果。

**材料**：一台能运行 Python 的电脑；纸和笔。

**步骤**：

1. 准备一段测试文字。建议用：`"   Python 是一门很适合初学者的编程语言。  "`，注意前后各有两个空格。
2. 在纸上先手工写下你预期的结果：去掉两端空格后有多少个字符？第 0 个字符是什么？最后一个是哪个字符？
3. 新建 `.py` 文件，把这段文字存成变量 `text`。
4. 用 `len()` 输出原始长度，再用 `strip()` 去掉两端空格后输出新长度。对比两个数字，验证是否和你第 2 步算的一致。
5. 输出第 0 个字符和最后一个字符（最后一个用负数索引）。
6. 用切片输出前 6 个字符（去掉空格以后的）。
7. 用 `replace()` 把"Python"替换成"Python 3"，输出结果。
8. 用 `f"..."` 输出一句话，把文字长度嵌进去，比如"这段文字有 xx 个字符"。
9. 再做一次拆分练习：把 `"apple,banana,cherry"` 用 `split(",")` 切开，输出切出来的段数和每一段。
10. 最后做一个验证：把第 9 步的结果用 `"-".join()` 重新连起来，看看和原来的样子有什么不同。

**完成判据**：程序能正常运行，没有报错；第 2 步的手工预测和第 4 步的实际输出一致（提示：原始长度比去掉空格后多 4）；能说清 `[0]` 和 `[0:6]` 这两种写法取出来的东西有什么不同；第 10 步的结果你能解释为什么和原来不一样。

**排查方法**：

- 如果报"索引超出范围"，检查你用的编号是不是超过了"长度减一"。记住编号从 0 开始。
- 如果切片的结果比你想要的多一个或少一个字符，检查"含头不含尾"这条规则。`s[1:4]` 取的是 1、2、3，不包括 4。
- 如果 `strip()` 之后长度没变，检查你的文字两端是不是真的有空格。如果空格是在引号外面的，那就不算字符串的内容。
- 如果 `replace()` 之后原来的变量没变，这是正常的——字符串方法不改变原字符串，它返回新的。你需要在结果上继续操作，或者重新赋值。
- 如果 `join` 报错，检查它的写法：分隔符在前，列表在后，中间用点连接。这是很多人第一次会写错的地方。

## 常见误区

### 误区一："字符串的编号从 1 开始"

**错误说法**：第一个字符是 `s[1]`。

**为什么错**：Python 里编号从 0 开始，`s[0]` 才是第一个字符。这个规则来自早期的编程习惯，虽然不是数学上最自然的，但几乎所有主流编程语言都这样。记错的后果是"差一个"——你想要第一个字符，拿到了第二个。

**正确理解**：记住"长度是 n，编号是 0 到 n-1"。用 `len(s) - 1` 可以得到最后一个字符的编号，不过更简单的办法是直接用 `s[-1]`。

### 误区二："切片和索引一样，超范围都会报错"

**错误说法**：`s[2:100]` 肯定会报错，因为 100 超出了长度。

**为什么错**：切片和索引的行为不一样。索引 `s[100]` 会报错，因为它要的是一个确定存在的字符；切片 `s[2:100]` 不会报错，因为它要的是"一段范围"，而这个范围在字符串结束的地方自然就停了。这个差别在实际写程序时很有用：不确定长度的时候用切片，就不用担心报错。

**正确理解**：索引要"精确存在"，切片可以"超出范围"。这是故意设计成这样的，不是缺陷。

### 误区三："调用方法会改变原来的字符串"

**错误说法**：写了 `s.lower()` 之后，`s` 就变成小写了。

**为什么错**：字符串是不可变的——它的内容一旦确定就不能被修改。`lower()`、`strip()`、`replace()` 这些方法都是返回一个新的字符串，原来的 `s` 一点都没变。如果你不把返回值存起来，这次调用就白做了。

```python
s = "Hello"
s.lower()
print(s)
```

输出还是 `Hello`。要得到小写，得写 `s = s.lower()`。

**正确理解**：字符串的方法会"返回新的"而不是"改掉原来的"。这个特点和列表不同，列表的 `append()` 会直接改掉列表本身。所以用字符串方法时，记得把结果存起来。

## 本章小结

- 字符串的编号从 0 开始，长度是 n 的字符串编号从 0 到 n-1；`s[-1]` 表示最后一个字符。
- 切片用 `[起:止]`，规则是"含头不含尾"；切片超出范围不报错，索引超出范围会报错。
- 常用方法有 `upper`、`lower`、`strip`、`replace`、`split`、`join`、`find`、`startswith`、`isdigit`。
- 字符串不可变：方法返回新字符串，不会改掉原来的，要用结果必须重新赋值。
- 格式化输出推荐用 f-string，写法是在引号前加 `f`，变量放在花括号里；用 `:.2f` 可以控制小数位数。
