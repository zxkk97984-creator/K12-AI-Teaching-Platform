# 组织数据：列表

## 学习目标

- 创建列表并按下标访问元素
- 对列表做增删改查和排序
- 用列表存放一组相关数据并遍历处理

## 开始之前

前面几章处理的数据都是"一个"。这一章要处理"一批"——二十个学生的成绩、十个待办事项、一本书里的所有单词。

先想一想这个问题：如果班里有四十个同学，你要把每个人的名字存进程序里，用变量存的话要写多少行？

材料：一台能运行 Python 的电脑；纸和笔。

## 情景导入

小雨想写一个程序，算她五门课的平均分。她写了五个变量：

```python
chinese = 88
math = 95
english = 79
physics = 82
chemistry = 90
```

然后算平均：

```python
average = (chinese + math + english + physics + chemistry) / 5
print(average)
```

老师说："如果明年多了一门生物呢？"

小雨说："那我再加一个变量，然后把除数改成 6。"

老师说："如果你们班四十个人都要算呢？"

小雨想了想说："那就得写四十乘五等于两百个变量，算的时候要写四十行。太麻烦了。"

老师说："问题的根源在于，你把'一批同类的东西'拆成了一个个单独的变量。这样做，每增加一个数据都要改代码。有没有办法把它们装在一个容器里？"

小雨说："就像把五本书放进一个书架？"

老师说："对。这个容器叫列表。有了列表，五个数据还是装一个变量，四十个数据也还是装一个变量。而且算平均分的代码一个字都不用改，因为它只知道'这是一个装分数的容器'，不关心里面有几个。"

## 知识讲解

### 创建列表和下标访问

列表是一串有序的数据，用方括号括起来，元素之间用逗号隔开：

```python
scores = [88, 95, 79, 82, 90]
names = ["小雨", "小北", "小然"]
mixed = [1, "小雨", 3.5, True]
```

列表里可以放不同类型的东西，不过实际使用时通常放同类的，这样处理起来才方便。

访问元素用下标，和上一章讲的字符串索引完全一样：**从 0 开始，支持负数**。

```python
scores = [88, 95, 79, 82, 90]
print(scores[0])
print(scores[-1])
print(len(scores))
```

输出 `88`、`90`、`5`。注意最后一个元素的编号是 4，而长度是 5。

超过范围的访问会报错：

```python
print(scores[5])
```

报 `IndexError: list index out of range`。这是很常见的错误，尤其是长度会变的时候。

列表有一个字符串没有的特点：**它可以被修改**。字符串是不可变的，而列表是可变的：

```python
scores = [88, 95, 79]
scores[0] = 90
print(scores)
```

输出 `[90, 95, 79]`。这一点很重要，它意味着你可以直接改列表里的某一项。记住这个对比：字符串的方法返回新字符串，而列表的很多方法直接改掉列表本身。

切片在列表上一样能用：

```python
print(scores[1:3])
print(scores[:2])
print(scores[::-1])
```

分别得到前三个示例里的第 2、3 项、前两项、以及倒过来的列表。

### 增删改查

列表的常用操作可以分成四类。

**增加元素。**

```python
scores = [88, 95]
scores.append(79)
print(scores)
```

输出 `[88, 95, 79]`。`append` 在末尾加一个。

要在指定位置插入，用 `insert`：

```python
scores.insert(0, 100)
print(scores)
```

输出 `[100, 88, 95, 79]`。第一个参数是位置，第二个是要插入的值。注意插入以后后面元素的位置都会往后移。

**删除元素。**

```python
scores = [88, 95, 79, 95]
scores.remove(95)
print(scores)
```

输出 `[88, 79, 95]`。`remove` 删除**第一个**匹配的值。如果这个值不存在，会报错。

要按位置删除，用 `pop`：

```python
scores = [88, 95, 79]
last = scores.pop()
print(last, scores)
```

输出 `79 [88, 95]`。`pop()` 不带参数时删除最后一项，并把它返回；带参数时删除指定位置。

**查找元素。**

```python
scores = [88, 95, 79]
print(95 in scores)
print(scores.index(95))
```

输出 `True` 和 `1`。`in` 判断在不在，`index` 返回第一次出现的位置，找不到会报错（这一点和字符串的 `find` 不同，`find` 找不到返回 -1）。

**统计和排序。**

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(sum(nums))
print(max(nums))
print(min(nums))
print(len(nums))
print(nums.count(1))
```

分别输出 `31`、`9`、`1`、`8`、`2`。

排序有两个方法，区别很重要：

```python
nums = [3, 1, 4, 1, 5]
sorted_list = sorted(nums)
print(sorted_list)
print(nums)

nums.sort()
print(nums)
```

`sorted(nums)` 返回一个新的排好序的列表，原来的 `nums` 不变。`nums.sort()` 直接改掉 `nums` 本身，返回 `None`。

这个区别是初学者最容易犯的错误之一：

```python
nums = [3, 1, 4]
nums = nums.sort()
print(nums)
```

输出 `None`。因为 `sort()` 返回的是 `None`，赋值把原来的列表覆盖掉了。正确写法是 `nums.sort()` 单独一行，或者 `nums = sorted(nums)`。

要倒序排，用 `reverse=True`：`sorted(nums, reverse=True)`。

**反转列表**用 `reverse()`（也是直接改掉自己）或者切片 `nums[::-1]`（返回新的）。

### 遍历和处理

遍历列表用 `for`：

```python
scores = [88, 95, 79]
for s in scores:
    print(s)
```

需要序号时用 `enumerate`：

```python
for i, s in enumerate(scores, start=1):
    print(f"第 {i} 门课：{s}")
```

如果既要值又要改列表，可以用下标遍历：

```python
for i in range(len(scores)):
    scores[i] = scores[i] + 5
```

这里 `range(len(scores))` 产生 0 到长度减一的所有下标。注意**不要用 `in` 遍历的同时修改列表的长度**，那会让循环的行为变得难以预测。需要删除元素时，通常的做法是"先生成一个新的列表，只保留要留的"：

```python
scores = [88, 95, 79, 55, 60]
passed = []
for s in scores:
    if s >= 60:
        passed.append(s)
print(passed)
```

输出 `[88, 95, 79, 60]`。这种写法比在原列表上边遍历边删除清楚得多。

列表推导式是这种写法的简写形式：

```python
passed = [s for s in scores if s >= 60]
```

它和上面那个循环完全等价，但更短。列表推导式很好用，不过刚开始建议先把普通循环写熟，再过渡到推导式。

### 嵌套列表

列表里可以放列表。这时候它就像一个表格：

```python
students = [
    ["小雨", 88, 95],
    ["小北", 92, 78],
    ["小然", 75, 88],
]
print(students[0])
print(students[0][1])
```

输出 `['小雨', 88, 95]` 和 `88`。`students[0]` 是第一行，`students[0][1]` 是第一行里的第二项。这种"两次下标"的写法是处理表格数据的基本方式。

遍历嵌套列表：

```python
for row in students:
    name = row[0]
    total = row[1] + row[2]
    print(f"{name} 的总分是 {total}")
```

输出三行。这里每一行是一个小列表，我们用 `row[0]`、`row[1]` 这样的下标取出各项。

要小心的是：**嵌套列表的元素是列表本身**。`students[0][0] = "小雨"` 这样的赋值可以改到里面。但如果把 `students[0]` 赋给一个变量再改那个变量，改的是同一个列表（因为列表是"引用"），这一点在学到函数传参时会更重要。

## 详细示例

### 示例一：算一组分数统计

**问题**：某次测验的成绩是 `[88, 95, 79, 62, 100, 45, 88, 73]`。请写程序算出：平均分（保留两位小数）、最高分、最低分、及格人数（60 分及以上）、以及每个分数与平均分之差。

**材料**：Python 环境；纸和笔。

**逐步推理**：

第一步，把分数存进列表：

```python
scores = [88, 95, 79, 62, 100, 45, 88, 73]
```

第二步，先手工核对几个数字。最高分是 100，最低分是 45。一共有 8 个数。

第三步，算平均分。用 `sum()` 和 `len()`：

```python
average = sum(scores) / len(scores)
print(f"平均分：{average:.2f}")
```

先手工验证：88 加 95 等于 183，加 79 等于 262，加 62 等于 324，加 100 等于 424，加 45 等于 469，加 88 等于 557，加 73 等于 630。630 除以 8 等于 78.75。输出应该是 `平均分：78.75`。

第四步，算最高分、最低分：

```python
print(f"最高分：{max(scores)}")
print(f"最低分：{min(scores)}")
```

输出 100 和 45，与手工一致。

第五步，算及格人数。用计数模式：

```python
pass_count = 0
for s in scores:
    if s >= 60:
        pass_count = pass_count + 1
print(f"及格人数：{pass_count}")
```

数一数：88 及格、95 及格、79 及格、62 及格、100 及格、45 不及格、88 及格、73 及格。一共 7 个及格。

第六步，算每个分数与平均分之差：

```python
for s in scores:
    diff = s - average
    print(f"{s} 与平均分相差 {diff:.2f}")
```

第一个：88 减 78.75 等于 9.25。验证一下程序会输出 `88 与平均分相差 9.25`。

第七步，把程序连起来运行，检查全部输出和手工结果一致。

**结果**：平均分 78.75、最高分 100、最低分 45、及格 7 人，各分数与平均分之差也正确。

**为什么正确**：我们把整组数据放在一个列表里，然后用 `sum`、`len`、`max`、`min` 这些内置函数和循环来计算。这样做的关键好处是：**如果成绩从 8 个变成 80 个，代码一个字都不用改**，因为 `len(scores)` 会自动得到正确的个数。

**一个边界情况**：如果这个列表是空的呢？`sum([])` 得到 0，`len([])` 得到 0，0 除以 0 会报 `ZeroDivisionError`。而 `max([])` 和 `min([])` 也会直接报错，说"空序列没有最大值"。所以在处理真实数据时，开头应该加一道检查：

```python
if len(scores) == 0:
    print("没有成绩数据")
else:
    ...正常的计算...
```

这说明**对列表做统计之前，要先考虑列表可能为空**。这不是吹毛求疵，因为从文件读取数据的时候，读到一个空文件是很常见的情况。

### 示例二：从名单里筛选和排序

**问题**：班级有一个名单 `["小然", "小北", "小雨", "小林", "小方"]`，对应的成绩是 `[75, 92, 88, 60, 95]`。请写程序：把分数低于 80 的同学名字找出来；把所有同学按分数从高到低排列，输出名次表。

**材料**：Python 环境；纸和笔。

**逐步推理**：

第一步，把两个列表准备好：

```python
names = ["小然", "小北", "小雨", "小林", "小方"]
scores = [75, 92, 88, 60, 95]
```

第二步，先手工对照一遍：小然 75、小北 92、小雨 88、小林 60、小方 95。低于 80 的是小然（75）和小林（60）。

第三步，找出低于 80 的名字。要注意"名字和分数在同一个位置"这个关系：

```python
below = []
for i in range(len(names)):
    if scores[i] < 80:
        below.append(names[i])
print(f"低于 80 分的有：{below}")
```

输出 `低于 80 分的有：['小然', '小林']`，与手工一致。

这里必须用下标遍历，因为要同时拿到名字和分数。如果只写 `for s in scores`，就拿不到对应的名字。

第四步，做名次表。思路是把名字和分数配对，然后按分数排序。配对可以用 `zip`：

```python
pairs = list(zip(names, scores))
print(pairs)
```

输出 `[('小然', 75), ('小北', 92), ('小雨', 88), ('小林', 60), ('小方', 95)]`。这是一个由"元组"组成的列表，每个元组里是名字和分数。

第五步，按分数从高到低排序。`sorted` 可以指定"按什么排"：

```python
ranked = sorted(pairs, key=lambda p: p[1], reverse=True)
```

`key=lambda p: p[1]` 的意思是"排序时看每个元素的第 2 项"，也就是分数。`reverse=True` 表示从大到小。

第六步，输出名次表：

```python
for i, (name, score) in enumerate(ranked, start=1):
    print(f"第 {i} 名：{name}，{score} 分")
```

手工验证排序结果：小方 95、小北 92、小雨 88、小然 75、小林 60。所以输出应该是：

```text
第 1 名：小方，95 分
第 2 名：小北，92 分
第 3 名：小雨，88 分
第 4 名：小然，75 分
第 5 名：小林，60 分
```

**结果**：程序正确找出低于 80 分的两位同学，并按分数正确排出名次。

**为什么正确**：关键的两步是"把两个列表配对"和"指定按哪一项排序"。配对用 `zip` 保证名字和分数不会错位；排序时用 `key` 告诉 `sorted` 看哪一项。如果不指定 `key`，`sorted` 会按元组的第一个元素（也就是名字）排序，那就不是我们要的结果了。

**一个边界情况**：如果两个人分数相同呢？比如小雨和小北都是 88 分。这时 `sorted` 是稳定的，它会保持原来列表里的相对顺序——原来小北在前，排完以后小北还是在前。这是可以接受的，但如果你想在分数相同时按名字排序，就需要把 `key` 改成先按分数降序、再按名字升序。单纯用 `key=lambda p: p[1]` 做不到这一点。这说明**排序规则如果不止一条，需要明确指定优先级**，否则结果虽然确定，但不一定是你想要的。

## 动手实践

**目标**：用列表管理一组数据，完成增删改查和统计。

**材料**：一台能运行 Python 的电脑；纸和笔。

**步骤**：

1. 先想清楚要管理什么数据。建议选：一周七天的运动时长、一本读书清单、五次测验的成绩、或者家里的购物清单。
2. 在纸上写下至少 6 个数据，并且算出你要统计的目标值（比如总和、平均值、最大值），记在纸上作为核对依据。
3. 在程序里把数据存成一个列表。
4. 输出列表的长度、第一个元素和最后一个元素。用 `len()` 和下标，最后一个用负数下标。
5. 用 `append()` 往列表末尾加一个新数据，再输出列表。
6. 用 `insert()` 在开头插入一个数据，输出列表。
7. 用 `remove()` 删除一个指定的值，输出列表。注意观察：如果这个值在列表里出现多次，删掉的是哪一个？
8. 用 `sorted()` 得到排好序的列表并输出，然后输出原列表，确认原列表没变。
9. 用 `sort()` 直接排序，再输出原列表，确认这次原列表变了。
10. 用循环算出总和和平均值，和你在第 2 步算好的目标值对照。
11. 做一个筛选：生成一个新列表，只保留大于平均值的那些数据。
12. 测试一个边界：用一个空列表 `[]` 做一次 `sum()` 和 `len()`，看看得到什么；然后再试试对空列表做 `max()`，观察报错信息。

**完成判据**：程序能正常运行；第 5 步到第 9 步每一步都观察到了列表的变化并记录下来；第 10 步的输出和第 2 步的手算一致；第 11 步的新列表内容你能解释（比如说明为什么这几个数被选中了）；第 12 步的两个观察都做了，并且你能说出空列表做 `max()` 时报的是什么错误。

**排查方法**：

- 如果报 `IndexError`，检查下标有没有超过"长度减一"。记住最后一个元素的下标是 `len(列表) - 1`。
- 如果 `remove()` 报错说找不到，检查要删的值是不是真的在列表里，注意类型也要一致（`"60"` 和 `60` 是不同的）。
- 如果排序以后列表变成了 `None`，检查是不是写了 `lst = lst.sort()`。`sort()` 直接改列表，返回 `None`。
- 如果平均值算出来不对，检查分母用的是不是 `len(列表)`，而不是你手写的数字。
- 如果结果和手算不一致，在循环里打印中间结果，把每一步看清楚。

## 常见误区

### 误区一："sort() 和 sorted() 是一样的"

**错误说法**：两个都是排序，随便用哪个。

**为什么错**：`sorted(列表)` 返回一个新的排好序的列表，原来的列表不变；`列表.sort()` 直接改掉原列表，返回 `None`。最危险的错误是写 `lst = lst.sort()`，这样 `lst` 会变成 `None`，后面的操作全部报错。

**正确理解**：想保留原列表就用 `sorted()`，想把原列表改掉就用 `.sort()`（单独一行，不要赋值）。这个"返回新值还是改自己"的区别，和上一章讲的字符串方法形成对比——字符串方法全都是返回新值。

### 误区二："边遍历边删除列表元素很方便"

**错误说法**：要删掉不及格的分数，写个循环遇到就删，最直接。

**为什么错**：在遍历的同时删除元素，会让后面的元素往前移，导致循环跳过一些元素。举个例子：

```python
nums = [1, 2, 3, 4, 5]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)
```

期待的结果是 `[1, 3, 5]`，但实际会得到 `[1, 3, 5]` 或者别的结果，取决于具体的删除过程。这类问题很难排查，因为程序不报错，只是结果不对。

**正确理解**：要筛选元素，就生成一个新列表，只保留要留的。这是最清楚也最不容易出错的做法。

### 误区三："列表和字符串差不多，方法也通用"

**错误说法**：字符串有的方法列表也有，用法一样。

**为什么错**：它们有一个根本区别——**字符串不可变，列表可变**。所以 `s.strip()` 返回新的字符串，而 `lst.append(x)` 直接改掉列表；`s = s.strip()` 是对的，而 `lst = lst.append(x)` 会让 `lst` 变成 `None`。另外方法名也有差别，比如字符串用 `find`（找不到返回 -1），列表用 `index`（找不到报错）；字符串用 `count` 是统计子串出现次数，列表用 `count` 也是统计元素出现次数。

**正确理解**：用方法之前先想一句："这个方法会返回新值，还是改掉原来的？"拿不准就查一下文档，或者写个小例子试一下。

### Q04 · 简答题

小雨想删掉列表里所有不及格的分数，她写成了：

```python
scores = [88, 45, 79, 55, 60]
for s in scores:
    if s < 60:
        scores.remove(s)

```

## 本章小结

- 列表是一串有序数据，下标从 0 开始、支持负数；列表可以被修改，这一点和字符串不同。
- 增加用 `append`、`insert`，删除用 `remove`、`pop`，查找用 `in`、`index`，统计用 `sum`、`max`、`min`、`len`、`count`。
- `sorted()` 返回新列表，`.sort()` 改掉原列表并返回 `None`；把 `sort()` 的结果赋值给变量是常见错误。
- 遍历用 `for`；需要同时拿到下标和值时用 `enumerate`；不要边遍历边删除元素，改为生成新列表。
- 嵌套列表可以用来表示表格，用两次下标访问里面的数据。

下一章我们要学字典。列表靠"第几项"来取数据，而字典靠"名字"来取数据，这在很多场景下更方便。
