# 机器学习原理与应用 · 前言

## 这本书写给谁

本书面向已经学过一门编程语言基础语法、并具备数据结构与算法基础的读者。你需要能读懂函数、循环、列表和字典，能自己写几十行的短程序。

## 先修要求

先确认你能独立完成：用 Python 定义函数并返回值；用循环和列表完成求和、计数、筛选；理解字典的“键到值”对应关系；会画折线图和散点图；知道什么是平均数。

接触向量、矩阵、导数、概率时不必紧张：本书只用到它们在中学数学范围内的含义，第二章会讲清需要的最小集合。

示例代码默认使用 Python 3.12，尽量只用标准库。涉及 `numpy` 或 `scikit-learn` 的段落会明确标注包名；没有标注的代码可以直接运行。所有示例数据都是合成的小数据，直接写在代码里。

## 学习路径

第一章回答一个基本问题：什么问题适合用机器学习解决，什么不适合。它不写模型，但决定了后面你有没有用对工具。

第二章提供必要的数学工具：向量、矩阵、距离、导数、概率——讨论“模型怎么学”时唯一能说清楚的语言。

第三到第五章是一条主线：把数据变成特征，把数据分成三份，然后训练第一个模型线性回归。这些章节会反复提醒数据泄漏这个陷阱，它是初学者最常犯、最不容易察觉的错误。

第六到第九章依次展开分类、决策树与集成、聚类、神经网络：同一个问题可以用不同模型解决，选择取决于数据特点和你能接受的代价。

第十章回到评估：过拟合与欠拟合、偏差与方差、学习曲线、指标选择。这是全书的收束。第十一章讨论生成式人工智能与责任，第十二章是综合项目，要求你完成一个**诚实的**预测系统。

## 每一章怎么用

每一章顺序相同：学习目标、开始之前、情景导入、知识讲解、详细示例、动手实践、常见误区、练习与自测、本章小结、延伸阅读。

知识讲解分四个小节，每节先说明这个概念解决什么问题，再说明内部机制，最后说明什么条件下适用、什么条件下会失效。详细示例完整展开计算过程。动手实践给出至少六个有序步骤和明确的完成判据。

常见误区一节请认真读。机器学习里很多说法直觉上很自然、实际上却是错的，比如“准确率高就说明模型好”“特征越多越好”。

## 关于数据的边界

本书只用合成数据或明确标注来源的公开数据，示例数据不具有现实统计意义。书中的准确率、误差等数字都附带“在什么数据上、用什么划分、什么阈值”这些条件，脱离条件的数字没有意义。

## 需要注意的边界

本书由 AI 辅助原创编写，未经过教师人工审校。数学推导和程序输出经过实际运行核对，但编排顺序和练习难度没有在真实课堂上验证过。来源链接是官方文档或权威机构页面，不代表本书内容经过这些机构认可。

关于人工智能的描述，本书遵循一条原则：**AI 是一个从数据中学习规律的系统**，它没有感受、不能理解、也不能保证不犯错。书中不会把它描述成能理解人类意图或必然正确的实体——这种描述既不准确，也会让人放松应有的核查。
