# 用模型做预测

## 学习目标

- 用训练好的模型预测新数据
- 说明预测结果为什么会有误差
- 区分预测置信与预测正确

## 开始之前

上一章我们用 k 近邻做出了第一次分类。这一章要把模型真正用起来：拿它去预测新数据，并且弄清楚预测为什么不可能永远正确。

先想一想这个问题：天气预报说"明天降水概率 70%"，这句话是什么意思？是"明天一定会下雨"吗？如果不是，那 70% 到底在说什么？

## 知识讲解

### 用模型做预测的完整流程

用训练好的模型预测新数据，要做几步，而且每一步的顺序不能乱。

```python
def predict_one(model_data, raw_features, scaler):
    """用训练好的模型预测一个样本。model_data 里包含训练特征和标签。"""
    scaled = scaler(raw_features)
    return knn_predict(model_data["X"], model_data["y"], scaled, k=model_data["k"])
```

关键是：**新样本必须用和训练时完全一样的预处理方式**。

假设训练时你对特征做了归一化，用的是训练集的最小值 1、最大值 6。现在来了一个新样本，它的第一个特征值是 0.5。你该怎么处理？

答案是：**用同一组最小值和最大值**，也就是 (0.5 - 1) / (6 - 1) = -0.1。

有时候新样本的值会超出训练集的范围，算出来是负数，这是正常的，不用"修正"它。

**如果你重新算了新样本所在数据的最小值和最大值，那就完全错了。** 因为这样一来，训练时的特征和新样本的特征就不在同一个尺度上了，距离算出来没有意义。

这是一个很实际的坑：训练时缩放用的参数，必须保存下来，预测时原样使用。所以在真实项目里，这些参数（最小值、最大值、平均值、标准差）是模型的一部分，要跟着模型一起保存。

还有一个顺序上的要求：**特征的选取顺序也要和训练时一致**。如果训练时特征的顺序是"花瓣长度、花瓣宽度"，预测时不能颠倒成"花瓣宽度、花瓣长度"——那样算出来的距离完全是另一回事。而且程序不会报错，只会给出错误的结果。

### 预测误差从哪里来

预测不可能百分之百正确。误差来自好几个地方。

**第一，数据本身带有噪音。** 测量会有误差（尺子量出来的长度每次都略有不同），记录会有笔误，回答会有偏差（有人高估自己的运动量）。这些噪音会让数据里出现"看起来一样但标签不同"的样本。

**第二，模型和数据不完全匹配。** 每个模型都有自己的假设。k 近邻假设"靠得近的样本属于同一类"，如果真实情况不是这样（比如两类数据交织在一起），模型再怎么调也好不到哪去。

**第三，训练数据不够全面。** 如果训练数据里没有出现过某一种情况，模型遇到它时就只能靠猜。第 6 章讲哈士奇和狼的例子就是这个：训练时的照片都在雪地里，模型没见过不下雪的场景。

**第四，特征里没有包含判断所需的信息。** 如果你只用两个特征去判断一件需要五个特征才能判断的事，那无论用什么算法，准确率都有上限。

**第五，类别边界本身就模糊。** 有些样本就是处在两类的交界处，连人都难以判断，机器自然更容易出错。这不是模型的问题，而是问题本身的性质。

理解误差的来源很重要，因为它决定了改进的方向。如果误差主要来自"训练数据不全"，那你该去收集更多数据；如果来自"特征不够"，那该去找更有用的特征；如果来自"边界模糊"，那也许应该接受这个误差，并且在使用时留出人工确认的环节。

### 概率与置信

很多分类模型不只是给出"是 A 类"，还能给出"是 A 类的可能性有多大"。这个数字叫概率或者置信度。

在 k 近邻里，一个自然的做法是：看 k 个邻居里各类占的比例。

```python
def knn_proba(train_X, train_y, query, k=5):
    """返回各类别的比例。"""
    dists = sorted(
        ((distance(x, query), train_y[i]) for i, x in enumerate(train_X)),
        key=lambda pair: pair[0],
    )
    neighbors = dists[:k]

    counts = {}
    for _, label in neighbors:
        counts[label] = counts.get(label, 0) + 1

    return {label: c / len(neighbors) for label, c in counts.items()}
```

用上一章的数据测试，k 取 5。如果 5 个邻居里 4 个是 A、1 个是 B，那么返回 `{"A": 0.8, "B": 0.2}`。

这个比例可以理解成"模型有多大的把握"。0.8 表示"比较有把握"，0.51 表示"几乎是在猜"。

**要特别注意一件事：这个"概率"并不是真正的概率。** 它只是"邻居里各类的比例"。如果 k=1，那比例不是 1 就是 0——模型永远"百分之百确定"，但这显然不能理解成它真的从不出错。所以：

**置信度高不等于预测正确。** 模型可能"非常自信地出错"。特别是当训练数据里有噪音、或者新样本落在训练数据没覆盖的区域时，模型给出的高置信度是不可信的。

### 置信不等于正确

这一节把上面那句话展开讲，因为它是本章最重要的一点。

举一个例子。假设你的训练数据里有一位同学的标签标错了——他实际是 A 类，但被标成了 B 类。现在来了一个新样本，它实际上和这位同学非常相似。k 近邻会认为它们很近，于是把这个新样本也判成 B，而且如果邻居里 B 占多数，置信度还会很高。

模型"自信地"给出了错误答案。**它不知道那条训练数据的标签是错的。**

再举一个例子。新样本落在了训练数据的空白区域（比如所有训练样本都在 0 到 10 之间，而新样本是 100）。这时距离最近的几个邻居其实都离它很远，它们和它未必真的相似。但算法还是会选出最近的 k 个，照样投票，照样给出一个置信度。这个结果完全没有依据，但模型不会告诉你这一点。

所以使用模型的预测结果时，要问三个问题。

**第一，这个样本落在训练数据覆盖的范围内吗？** 如果离得很远，预测就不可靠。

**第二，训练数据的标签可靠吗？** 如果标签本身有错，模型会自信地重复这个错误。

**第三，这个判断如果错了，后果严重吗？** 后果严重的话，就不能完全依赖模型的输出。

那"置信度"有什么用？它的用处是**区分哪些预测值得信任、哪些需要额外检查**。你可以规定：置信度高于某个值的直接采用，低于这个值的人工复核。这是实际系统里很常见的做法——**用置信度来决定"要不要找人看"，而不是用来宣称"我的答案是对的"**。

## 详细示例

### 示例一：完成一次预测并分析误差

**问题**：用下面这份训练数据，对三个新样本做预测，并分析哪一个预测最不可靠。

```python
train_X = [[1, 1], [2, 1], [1, 2], [2, 2], [3, 2],
           [8, 8], [9, 8], [8, 9], [9, 9], [7, 9]]
train_y = ["A", "A", "A", "A", "A", "B", "B", "B", "B", "B"]
# 三个新样本
queries = [[1.5, 1.5], [8.5, 8.5], [20, 20]]
```

**材料**：Python 环境；一支笔、一本练习本。

**逐步推理**：

第一步，先看训练数据的分布。A 类集中在 (1,1) 到 (3,2) 这一小片区域；B 类集中在 (7,9) 到 (9,9) 这一片。两类离得很远，中间有很大的空白。

第二步，预测第一个样本 (1.5, 1.5)。它就在 A 类的中心区域。算距离：到 (1,1) 是根号 0.5 约 0.707；到 (2,1) 是根号 0.5 约 0.707；到 (1,2) 也是约 0.707；到 (2,2) 约 0.707；到 (3,2) 约 1.581。

最近的 5 个（k=5）里，前四个距离都是 0.707，都是 A 类。所以预测结果是 A，置信度是 1.0（五个邻居全是 A）。

这个预测很可靠：样本落在 A 类的密集区域，最近的邻居都很近而且类别一致。

第三步，预测第二个样本 (8.5, 8.5)。它在 B 类的中心区域。同理，最近的邻居都离得很近而且都是 B。预测结果是 B，置信度高。同样可靠。

第四步，预测第三个样本 (20, 20)。它离所有训练数据都远——最近的 (9,9) 距离是根号(121 + 121) 约 15.6，(8,9) 约 16.6。**这些距离比第一个样本的距离（0.707）大了二十多倍。**

问题在于：算法仍然会选出最近的 k 个，然后投票。这次 B 类可能会占多数（因为 B 类离得稍微近一点），于是预测结果是 B。

但这个预测**完全没有依据**。因为 (20, 20) 离所有的训练样本都很远，最近的邻居和它未必有任何相似性。而且从数据分布看，(20, 20) 这个位置可能属于一个训练数据里根本没出现过的第三类。

第五步，比较三个预测的可靠性。

- 第一个：距离近、邻居一致、落在覆盖范围内，可靠。
- 第二个：距离近、邻居一致、落在覆盖范围内，可靠。
- 第三个：距离远、落在覆盖范围之外，**不可靠，不应该采信**。

第六步，想怎么让程序自己发现这个问题。一个实用的办法是**记录最近邻居的距离**。如果这个距离超过某个阈值，就标记为"不确定"。

```python
def predict_with_warning(train_X, train_y, query, k=5, max_distance=5.0):
    dists = sorted(
        ((distance(x, query), train_y[i]) for i, x in enumerate(train_X)),
        key=lambda pair: pair[0],
    )
    neighbors = dists[:k]
    votes = {}
    for _, label in neighbors:
        votes[label] = votes.get(label, 0) + 1
    best = max(votes, key=votes.get)

    nearest = neighbors[0][0]
    if nearest > max_distance:
        return best, nearest, "距离过远，预测不可靠"
    return best, nearest, "正常"
```

对 (20, 20) 调用这个函数，最近距离约 15.6，超过阈值 5.0，所以会返回"距离过远，预测不可靠"。**程序自己主动说出了"我不确定"。**

**结果**：前两个样本的预测可靠；第三个样本虽然也能得到一个预测结果，但因为离训练数据太远，这个结果不应采信。加上距离检查以后，程序能自己标记出这种情况。

**为什么正确**：我们用的判断依据是"新样本离训练数据有多近"。距离近说明它在模型"见过"的区域里，预测有依据；距离远说明它在空白区域，预测等于瞎猜。这个检查对任何基于距离的模型都适用。

**一个边界情况**：如果训练数据里所有的样本都离得很远，那阈值怎么定？这时可以看训练数据本身的"典型间距"——比如算出每个训练样本到它最近邻居的距离，取一个典型值，然后把阈值定在这个值的几倍。这样阈值就是根据数据自适应出来的，而不是拍脑袋定一个数。**有依据的阈值比随便定的阈值可靠得多。**

### 示例二：分析一个"自信的错误"

**问题**：某模型的训练数据里有 3 条标签标错的样本（实际是 A 类，被标成了 B 类）。请分析这个错误会对预测造成什么影响，以及怎么发现它。

**材料**：上面的情况说明；一支笔、一本练习本。

**逐步推理**：

第一步，理解这 3 条错误标签在训练时会发生什么。模型不知道这是错的，它会把它们当作正确的答案来学习。k 近邻的"学习"就是记住这些数据，所以这 3 条错误标签会被原样保留。

第二步，分析它们的影响范围。错误标签的影响是**局部的**——只有那些离这 3 条数据很近的新样本才会被带偏。如果这 3 条恰好聚在一起，那么它们会在 A 类的地盘上造成一个"B 类的小岛"。

第三步，具体推演。假设有一条样本 (2, 2) 实际是 A 类，但标签写成了 B。现在来了一个新样本 (2.1, 2.1)，它离 (2, 2) 最近，距离约 0.14。取 k=3，假设另外两个最近邻居是 A 类。那么三个邻居里两个 A、一个 B，预测还是 A——错误标签被"投票"抵消了。

但如果 k=1 呢？最近的只有那条错误标签，预测就是 B。**k 小的时候错误标签的影响更大。**

第四步，分析置信度的情况。如果这 3 条错误标签聚在一起（比如都在 (2, 2) 附近），那么一个新样本落在这一片时，最近的 k 个邻居可能大部分都是这些错误标签。这时模型会给出一个很高的置信度，但答案是错的。**这就是"自信的错误"。**

第五步，想怎么发现标签错误。有几个办法。

**办法一：检查这类"孤立的点"。** 如果一个标签为 B 的样本周围全是 A 类的样本，它就很可疑。这个检查可以自动做：对每个训练样本，看它最近的 k 个邻居的标签，如果不一致，就标记出来。

**办法二：在训练集上做交叉验证。** 把训练集分成几份，轮流用其中一份当验证集，看看哪些样本总是被预测错。老是被预测错的样本，标签很可能有问题。

**办法三：人工复核。** 把可疑的样本挑出来，回原始记录核对。这是最可靠的办法，但需要人工。

第六步，想处理办法。发现标签错误以后：如果能确认，就改正它并重新训练；如果不能确认，可以考虑把这条样本从训练数据里去掉；如果只是怀疑，就在报告里说明"有 N 条样本的标签可能存在错误"。

**结果**：3 条错误标签会在它们附近造成局部的错误预测，k 越小影响越大；如果它们聚在一起，还会导致"自信的错误"。发现办法包括检查孤立点、交叉验证和人工复核。

**为什么正确**：我们从"错误标签如何影响邻近区域的预测"这个角度分析，得出了"影响是局部的、k 小时更严重、聚集时会造成高置信度的错误"这几个结论。这几个结论都可以用 k 近邻的工作原理推出来，不是猜测。

**一个边界情况**：如果错误标签不是 3 条而是 30 条（占总数很大比例）呢？那影响就不再是局部的了——模型学到的规律本身就被扭曲了。这时无论用什么 k，效果都不会好。**这说明"局部噪音"和"系统性错误"要区别对待**：前者可以靠调整 k 来缓解，后者必须从数据源头解决。判断的办法是看错误标签是随机分布的还是成片分布的。

## 动手实践

**目标**：用训练好的模型完成预测，并检查哪些预测不可靠。

**材料**：一台能运行 Python 的电脑；一支笔、一本练习本。

**步骤**：

1. 用上一章准备的训练数据（或者重新编一份，至少 16 个样本、两类）。先把数据划分成训练集和测试集（比例 7:3）。
2. **只用训练集**算缩放用的最小值和最大值，把它们记在纸上。这个数字后面要用。
3. 用这组参数处理训练集和测试集。注意：**测试集必须用训练集的参数，不能重新算。**
4. 实现带置信度的预测函数，返回预测类别和各类的比例。
5. 对测试集里的每一个样本做预测，把"预测类别""真实类别""置信度"三项记成一张表。
6. 算出准确率。找出预测错误的那些样本，看看它们的置信度是高还是低。
7. 统计一下：置信度高的样本里，错误率是多少？置信度低的样本里，错误率是多少？**它们有没有明显的差别？**
8. 做距离检查。对每个测试样本，记录它到最近训练样本的距离。
9. 找出距离最大的那两三个测试样本，看看它们的预测准不准。**距离大的样本是不是更容易预测错？**
10. 故意做一次"自信的错误"实验：把训练集里某一条样本的标签改错，重新训练，然后对那条样本附近的测试样本做预测。看看置信度有没有变化。
11. 写一段结论：在你的数据上，置信度和预测正确率有没有关系？距离和预测正确率有没有关系？如果要做一个人工复核的规则（比如"置信度低于多少就找人看"），你会把阈值定在哪里？

**完成判据**：数据划分正确；缩放参数只从训练集算出并记录下来；测试集用的是训练集的参数；置信度预测函数正确；测试结果表格完整；算出了准确率；比较了高低置信度样本的错误率；记录了到最近训练样本的距离；第 10 步的"自信的错误"实验做了并观察到了现象；结论里有具体的数字支持，并且给出了一个人工复核的阈值建议。

**排查方法**：

- 如果准确率异常高（比如 100%），先检查有没有数据泄漏——最可能是测试集用了自己算的缩放参数。
- 如果置信度总是 1.0，检查 k 是不是设成了 1。k=1 时置信度不是 1 就是 0，没有意义。
- 如果所有预测都一样，检查 k 是不是太大了（接近训练样本数）。
- 如果预测结果和上一章不一样，检查特征的顺序有没有变。**顺序变了结果就全变了，而且不会报错。**
- 如果距离算出来特别大，检查缩放有没有真的生效。
- 如果发现置信度和正确率没有关系，这也是一个有价值的发现——说明在这个数据上置信度不是可靠的信号。在报告里如实写出来。

## 常见误区

### 误区一："置信度 90% 就意味着十次里对九次"

**错误说法**：模型说 90% 的把握，那就是说它大概有九成的正确率。

**为什么错**：k 近邻给出的"置信度"其实只是"邻居里各类的比例"，它没有经过校准。只有当模型训练得很好、数据很干净、新样本又落在训练数据覆盖的范围内时，这个比例才大致和实际正确率对得上。如果标签有错、或者新样本落在空白区域，高置信度完全可能对应着低正确率。

**正确理解**：把置信度当成"模型有多确定"，而不是"答案有多大概率正确"。它的实际用途是**排序**——找出哪些预测最需要检查，而不是给出一个真实的正确率。

### 误区二："模型错了说明模型不行，换个更好的算法就行"

**错误说法**：准确率不高，那就换一个更高级的算法。

**为什么错**：误差的来源有很多种，换算法只能解决其中一部分。如果问题出在"训练数据里没有这种情况"（比如没有夜晚拍的照片），那把 k 近邻换成再高级的算法也没用——它同样没见过夜晚的照片。如果问题出在"标签标错了"，换算法只会把错误学得更牢。

**正确理解**：先诊断误差的来源，再决定怎么改。数据的问题用数据解决（补数据、修标签）；特征的问题用特征解决（找更好的特征）；只有确认是算法不适配时，才考虑换算法。**大多数时候，改进数据比改进算法有效得多。**

### 误区三："预测时重新算缩放参数也一样"

**错误说法**：归一化就是缩放到 0 到 1，预测时按新数据重新算一遍最小值最大值不就行了。

**为什么错**：如果预测时用自己的最小值和最大值重新缩放，那么同一个特征值在训练时和预测时会变成不同的数。比如训练集里最小值是 1、最大值是 6，某个值是 3 会变成 0.4；而如果新来的一批数据最小值是 0、最大值是 10，同一个值 3 会变成 0.3。**同一个数值被映射到了两个不同的位置**，训练时学到的"距离关系"就完全失效了。

**正确理解**：缩放的参数是模型的一部分。训练时用什么参数，预测时就原样使用，即使新样本的值超出了训练范围（算出来是负数或大于 1）也不改。

## 本章小结

- 预测新样本时，必须用训练时保存的缩放参数和相同的特征顺序；重新计算缩放参数会让训练和预测不在同一尺度上。
- 预测误差来自多个方面：数据噪音、模型与数据不匹配、训练数据不全面、特征信息不足、类别边界本身模糊。
- 分类模型可以给出置信度（各类的比例），但它不是校准过的概率；置信度高不等于预测正确。
- 模型会"自信地出错"，尤其是在标签有误或新样本超出训练范围时。
- 置信度最实用的用途是排序——找出哪些预测需要人工检查，而不是宣称答案正确。
