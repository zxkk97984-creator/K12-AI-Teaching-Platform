# 把数据画出来

## 学习目标

- 按数据类型选择合适的图表
- 用代码绘制并读懂柱状图与折线图
- 识别图表中误导人的画法

## 开始之前

上一章我们用几个数字描述数据。可是数字会掩盖很多信息。这一章要把数据画出来。

先想一想这个问题：如果你要看一周七天每天的气温变化，用表格和用图，哪个更容易看出趋势？为什么？

材料：一台能运行 Python 的电脑；一支笔、一本练习本。

## 情景导入

小雨把上次统计的睡眠数据整理成了一句话："本班同学平均每天睡 7.7 小时。"

老师看了看说："这句话没错，但我看不出任何别的东西。有没有人睡得特别少？大家的睡眠时间是集中还是分散？"

小雨说："我把每个选项的人数数了一遍：6 小时以内的有 3 人，6 到 7 小时的有 7 人，7 到 8 小时的有 12 人，8 到 9 小时的有 8 人，9 小时以上的有 2 人。"

老师说："这样就好多了。不过你刚才说的这一串数字，如果画成图会怎么样？"

小雨在纸上画了五个柱子，高度分别是 3、7、12、8、2。

画完以后她说："啊，一眼就看出来了——最多的人集中在 7 到 8 小时这一段，两边都少。像一个山峰。"

老师说："这就是画图的价值。**同样一组数据，画成图以后，形状、集中在哪里、有没有异常，都能一眼看出来**，而看一串数字要费劲得多。"

## 知识讲解

### 先看数据类型再选图

选图表的第一步不是挑好看，而是看你要画的是哪一类数据。

**数值型数据**是可以做加减、算平均的，比如时长、分数、温度、人数。**分类型数据**是分类的标签，没有大小关系，比如颜色、科目、运动项目。

这两类数据适合的图不同。

| 你想表达什么 | 数值型数据 | 分类型数据 |
| --- | --- | --- |
| 比较各类别的大小 | 柱状图 | 柱状图 |
| 看随时间的变化 | 折线图 | 一般不用 |
| 看两个量的关系 | 散点图 | 一般不用 |
| 看分布的形状 | 直方图 | 柱状图 |

有一个常见的错误：**给分类型数据画折线图**。折线图的含义是"从一个点到下一个点是连续变化的"，而类别之间没有连续性。比如把"语文、数学、英语"画成折线，连起来的线没有任何意义。

反过来，如果数据本身是随时间变化的（比如一周七天的气温），用折线图就能看出趋势，比柱状图更清楚。

### 柱状图

柱状图用柱子的高度表示数量，适合比较不同类别。

```python
import matplotlib.pyplot as plt

labels = ["6小时以内", "6-7小时", "7-8小时", "8-9小时", "9小时以上"]
counts = [3, 7, 12, 8, 2]

plt.bar(labels, counts)
plt.xlabel("睡眠时长")
plt.ylabel("人数")
plt.title("本班同学睡眠时长分布")
plt.show()
```

运行前需要安装 `matplotlib`。**它不属于 Python 标准库**，要用 `pip install matplotlib` 安装（建议 3.7 或更高版本）。如果没有安装，程序会报 `ModuleNotFoundError`。

画柱状图要注意几点。

**柱子的起点要从 0 开始。** 这是最重要的一条。如果纵轴不从 0 开始，柱子的高度比例就被扭曲了，看的人会得到错误的印象（这一点后面还会详细讲）。

**柱子的宽度要一致，间隔也要一致。** 不一致会让人误以为某些类别更重要。

**类别多的时候要考虑横过来。** 如果类别名字很长（比如"6小时以内"这种），横着排会挤在一起。可以用 `plt.barh` 画横向的条形图。

如果类别本身就是数值区间（比如上面这个睡眠时长的例子），柱状图还有一个变体叫直方图。直方图的特点是**柱子紧挨着，中间没有缝隙**，因为数值是连续的。这个细节很重要：有缝隙表示类别之间是分开的，没缝隙表示数值是连续的。

### 折线图

折线图用线把数据点连起来，适合看趋势。

```python
import matplotlib.pyplot as plt

days = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
temps = [22, 24, 21, 19, 23, 26, 25]

plt.plot(days, temps, marker="o")
plt.xlabel("日期")
plt.ylabel("气温（摄氏度）")
plt.title("一周气温变化")
plt.show()
```

`marker="o"` 表示在每个数据点上画一个小圆点，这样能看清每个实际测量的位置。

折线图要注意几点。

**横轴通常是时间。** 折线图的含义是"顺着横轴的方向变化"，所以横轴有顺序的时候才用它。

**点太少的时候不要用折线图。** 如果只有两个点，连起来就是一条直线，看不出任何趋势。一般来说至少要有五六个点。

**不要给不连续的数据连折线。** 比如你只有周一、周三、周五的数据，周二和周四没测，那么连起来的线会让人以为中间那两个点也存在。这种情况应该用散点图，或者在图上标明哪些点是实际数据。

**纵轴要标单位。** 气温是摄氏度还是华氏度，差别很大。

### 散点图

散点图用一个点表示一个数据，横纵坐标分别是两个量。它用来**看两个量之间有没有关系**。

```python
import matplotlib.pyplot as plt

study_hours = [1, 2, 2, 3, 3, 4, 5, 6]
scores = [58, 62, 70, 68, 75, 80, 85, 88]

plt.scatter(study_hours, scores)
plt.xlabel("每天学习时间（小时）")
plt.ylabel("测验分数")
plt.title("学习时间与测验分数的关系")
plt.show()
```

从这张图上看，点大致沿着一条向右上方的线分布，说明"学习时间越长，分数倾向于越高"。这叫"正相关"。

但要特别小心一件事：**散点图上看起来有关系，不等于有因果关系**。这一点在第 1 章讲过，在第 12 章还会再遇到。眼见不一定为实——可能是第三个因素同时影响了两者。

### 坐标轴与比例

坐标轴怎么设，会直接影响图表给人的印象。这是"图表会骗人"的主要来源。

**第一条：柱状图的纵轴必须从 0 开始。**

假设有两个班，甲班 40 人，乙班 42 人。如果柱状图的纵轴从 38 开始，那么甲班的柱子高 2 个单位，乙班高 4 个单位——看起来乙班是甲班的两倍。但实际上 42 和 40 只差 5%。**这就是用截断的纵轴制造假象。**

折线图在特殊情况下可以截断纵轴（因为它主要表达趋势，不是比较绝对量），但必须在图上明确标出来，否则同样会误导。

**第二条：纵轴的比例要合理。**

如果纵轴的范围设得太大（比如数据在 20 到 30 之间，纵轴却从 0 到 1000），所有的变化都被压成一条平线，看不出任何东西。反过来，如果范围设得太小，一点小波动会被放大成剧烈变化。

**第三条：横轴的间隔要均匀。**

如果横轴是按时间排的，但刻度之间的间隔不均匀（比如标了 1 日、2 日、10 日、11 日，却排成等距），那么时间的变化就被扭曲了。

**第四条：不要用面积和体积表示一维的量。**

如果用一个圆的面积表示人数，半径和面积的关系是平方关系。人数翻一倍，半径只需要变成原来的 1.4 倍。但如果画图的人把半径翻倍，看起来面积就变成了 4 倍，让人误以为人数是 4 倍。所以要比较数量，就用柱子的高度，不要用圆的面积。

## 详细示例

### 示例一：为不同数据选择并绘制图表

**问题**：下面是三组数据。请为每一组选择最合适的图表类型，说明理由，并写代码画出来。

```text
数据一：周一至周日七天的运动时长（分钟）：30、45、20、60、15、90、50
数据二：四种运动项目的参与人数：跑步 12 人、球类 15 人、游泳 4 人、其他 7 人
数据三：八位同学的每天学习时长与测验分数
```

**材料**：Python 环境（需要安装 matplotlib）；一支笔、一本练习本。

**逐步推理**：

第一步，分析数据一。它是随时间变化的数据，横轴是星期，有自然顺序。看趋势用折线图最合适。

第二步，分析数据二。它是分类型数据（运动项目没有大小关系），要比较各类别的多少，用柱状图最合适。不能用折线图，因为项目之间没有连续性。

第三步，分析数据三。它有两个数值型变量，要看它们之间有没有关系，用散点图最合适。

第四步，画数据一的折线图：

```python
import matplotlib.pyplot as plt

days = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
minutes = [30, 45, 20, 60, 15, 90, 50]

plt.plot(days, minutes, marker="o")
plt.xlabel("星期")
plt.ylabel("运动时长（分钟）")
plt.title("一周运动时长变化")
plt.show()
```

从图上看，运动时长在某一天降到最低（15 分钟），在周六达到最高（90 分钟）。**这些信息看数字也能看出来，但看图能更快地发现"有起伏"。**

第五步，画数据二的柱状图：

```python
labels = ["跑步", "球类", "游泳", "其他"]
counts = [12, 15, 4, 7]

plt.bar(labels, counts)
plt.xlabel("运动项目")
plt.ylabel("参与人数")
plt.title("运动项目参与情况")
plt.ylim(0, 18)
plt.show()
```

注意这里设置了 `plt.ylim(0, 18)`，明确让纵轴从 0 开始，最大值略高于最高的柱子（15），这样既能看到差别又不浪费空间。

第六步，画数据三的散点图：

```python
study = [1, 2, 2, 3, 3, 4, 5, 6]
scores = [58, 62, 70, 68, 75, 80, 85, 88]

plt.scatter(study, scores)
plt.xlabel("每天学习时间（小时）")
plt.ylabel("测验分数")
plt.title("学习时间与分数的关系")
plt.show()
```

第七步，解读三张图。数据一的图显示运动时长有起伏，周六最多；数据二的图显示球类最受欢迎，游泳最少；数据三的图显示两个量大致同向变化。

第八步，给数据三的图加一句重要的提醒。**"同向变化"不等于"学得久导致分数高"。** 也可能是"本来就喜欢这门课的同学既愿意多学、也考得好"，或者"基础好的同学学起来轻松、所以愿意多花时间"。要看因果，需要做对照实验。

**结果**：数据一用折线图、数据二用柱状图、数据三用散点图，三张图都正确画出来了，并且每一张都说明了自己的理由和要注意的地方。

**为什么正确**：我们按"数据有几维、是什么类型、想表达什么"来选择图表。时间序列用折线，类别比较用柱状，两个数值的关系用散点。这个判断顺序对任何数据都适用。

**一个边界情况**：如果数据一的七天里，有两天没有记录（比如周三和周四忘了记），还能画折线图吗？这时要特别小心。如果直接把周一、周二、周五的点连起来，图上会显示一条从周二直接到周五的线，看的人会以为这三天都有数据。正确的做法有两种：一是用散点图，只标出有数据的点；二是在折线图上把缺失的位置断开（不连线），并用虚线或者标记说明。**图不能比数据"多说"什么**，这一点是画图的基本要求。

### 示例二：识别一张误导人的图表

**问题**：下面是两张图的描述。请分别判断它们有没有误导，说明误导在哪里，并写出改进办法。

```text
图 A：比较甲班和乙班的平均分。甲班 82 分，乙班 84 分。
      柱状图的纵轴从 80 开始，甲班的柱子高度是 2，乙班是 4。
      图标题写着"乙班成绩远超甲班"。

图 B：比较三种零食的热量。薯片 500 千焦，巧克力 520 千焦，饼干 510 千焦。
      用三个不同大小的圆形表示，圆的半径分别是 5 厘米、10 厘米、7.5 厘米。
```

**材料**：上面的两个描述；一支笔、一本练习本。

**逐步推理**：

第一步，分析图 A 的第一个问题：纵轴截断。纵轴从 80 开始，那么甲班的柱子（82）只比底线高 2，乙班（84）高 4。看起来乙班是甲班的两倍。但实际上 84 比 82 只高了 2 分，相对差距是 2 除以 82 约等于 2.4%。

第二步，分析图 A 的第二个问题：标题夸大。标题写"远超"，而实际差距只有 2.4%，这个描述与数据不符。**图表本身已经夸大了差异，标题又把结论再夸大了一层。**

第三步，给出图 A 的改进办法：把纵轴改到从 0 开始。这样甲班的柱子高 82，乙班高 84，两者看起来几乎一样高，这才是符合事实的印象。同时把标题改成中性的表述，比如"甲班与乙班的平均分对比"，让读者自己看差距。

第四步，分析图 B 的问题：用面积表示一维的量。圆的半径是 5、10、7.5，看起来第二个是第一个的两倍、第三个是 1.5 倍。但圆的面积和半径的平方成正比，所以三个圆的面积比是 25 比 100 比 56.25，也就是 1 比 4 比 2.25。

第五步，算一算实际的数据比例。热量是 500、520、510，比例大约是 1 比 1.04 比 1.02。**三个数字其实非常接近，差别只有 2% 到 4%。** 但图上看起来差了 4 倍。

第六步，给出图 B 的改进办法：改成柱状图，纵轴从 0 开始。这样三个柱子几乎一样高，读者一眼就能看出"这三种零食的热量差不多"。

第七步，总结这两张图的共同点。它们的误导方式不同（一个是截断坐标轴，一个是用面积表示一维量），但本质是同一个问题：**图表的视觉比例与数据的实际比例不一致，而且这种不一致倾向于夸大差异。**

**结果**：图 A 通过截断纵轴把 2.4% 的差距夸大成两倍，标题又进一步夸大；图 B 用圆面积表示热量，把 2% 的差距夸大成 4 倍。两张图都应该改成纵轴从 0 开始的柱状图，并使用中性标题。

**为什么正确**：我们用的判断办法是"算出数据之间的实际比例，再和图表给人的视觉比例比较"。两者的差距越大，误导就越严重。这个方法适用于任何一张图。另外要注意：**纵轴是否从 0 开始，对柱状图是硬性要求**，因为柱状图是靠"长度"表达量的；而折线图主要表达趋势，截断纵轴在特殊情况下可以接受，但必须标明。

**一个边界情况**：如果两张图的数据差异真的很大呢？比如甲班 20 分、乙班 90 分，纵轴从 0 开始。这时柱子的高度比是 1 比 4.5，看起来差别很大，但这次差别是**真实的**。所以问题不在于"图看起来差别大"，而在于"图的视觉比例和实际比例是否一致"。**正确地展示真实的巨大差异，不叫误导。**

## 动手实践

**目标**：为三组不同的数据选择并绘制合适的图表，并检查自己的图有没有误导。

**材料**：一台能运行 Python 的电脑（需要安装 matplotlib）；一支笔、一本练习本。

**步骤**：

1. 准备三组数据。第一组是随时间变化的（至少 7 个点，比如一周每天的某件事）；第二组是分类型的（至少 4 个类别）；第三组是两个量、想看看有没有关系（至少 8 对数据）。
2. 把三组数据都写在纸上。对每一组写一句："我想用它表达什么？"
3. 根据"想表达什么"为每一组选图表类型，并把理由写下来。特别注意别给分类型数据选折线图。
4. 画第一张图（折线图）。画完以后检查三件事：横轴是不是有顺序的？点够不够多（至少 5 个）？有没有把没数据的点连起来？
5. 画第二张图（柱状图）。检查纵轴有没有从 0 开始，柱子的宽度和间隔是不是一致的。
6. 画第三张图（散点图）。画完以后写一句话，记下你观察到的倾向。然后再写一句话，提醒"这不能证明因果"。
7. 现在做一次自查：对每一张图问"这张图有没有夸大差异"。检查的办法是算一下数据里两个值的实际比例，再看看图上看起来的比例，两者差得多不多。
8. 故意做一张误导人的图：把你第二张图的纵轴起点改成接近最低值的数，看看视觉上发生了什么变化。把这张图和正确的版本并排放着比较。
9. 写一段说明，讲清楚第 8 步那个"被篡改"的版本误导在哪里，以及为什么纵轴必须从 0 开始。
10. 最后给三张图都加上完整的标注：横轴名称和单位、纵轴名称和单位、标题。检查有没有漏。

**完成判据**：三组数据各自选了合适的图表类型并写下了理由；三张图都画出来了；第 4 到第 6 步的检查都做了，尤其第 6 步的因果提醒不能漏；第 7 步的比例检查做了；第 8 步的对照图做出来了；第 9 步的说明指出了纵轴截断造成的夸大；三张图都有完整的标注。

**排查方法**：

- 如果报 `ModuleNotFoundError: No module named 'matplotlib'`，说明还没有安装这个库。用 `pip install matplotlib` 安装。**这一章需要联网安装第三方库，属于外部依赖**，如果环境不允许，可以把数据画在纸上，重要的是选择图表的思路和检查误导的方法。
- 如果图上中文显示成方框，说明默认字体不支持中文。可以设置字体，或者临时改用英文标签。
- 如果图上的点挤在一起看不清，调整横纵轴的范围，或者把数据分组统计后再画。
- 如果不知道纵轴范围怎么定，柱状图从 0 开始，上限定成最大值再留一点余地。
- 如果画出来的图完全看不出信息，检查是不是把类别搞错了（比如给分类型数据画了折线），或者数据范围设得太宽。

## 常见误区

### 误区一："图表越好看越有说服力"

**错误说法**：把图做得漂亮一点，别人就更容易接受我的结论。

**为什么错**：图表的目的是**准确地**传递信息，不是说服别人。如果为了好看而调整坐标轴、放大某些柱子，图就变成了误导工具。而且这种误导常常不是故意的——设计者自己也被自己的图骗了。所以判断一张图好不好，标准是"看的人得到的印象和数据本身一致吗"，不是"看起来漂亮吗"。

**正确理解**：图表的首要要求是准确。坐标轴从 0 开始、比例一致、标注完整，这些比配色和装饰重要得多。

### 误区二："折线图到处都是，随便用"

**错误说法**：折线图直观，什么数据都能画。

**为什么错**：折线图的含义是"顺着横轴连续变化"。如果横轴是没有顺序的类别（比如运动项目、科目），连起来的线就没有意义，甚至会误导——看的人会以为"从跑步到球类"有一个渐变过程，实际上它们只是并列的类别。另外，如果横轴有顺序但某些位置没有数据，连起来的线会让人以为那些位置也有数据。

**正确理解**：折线图只用于横轴有顺序（通常是时间）的情况，而且要注意不要跨越没有数据的区间连线。

### 误区三："图上看起来差别很大，说明差别确实很大"

**错误说法**：你看这个柱子比那个高好多，肯定差很多。

**为什么错**：柱子的高度差受纵轴起点影响极大。纵轴从 0 开始时，两个柱子的高度比就是数值比；纵轴从接近最小值开始时，同样的两个数值会显示出巨大的高度差。所以**光看柱子的相对高度不能判断数值差距，必须看纵轴的范围**。

**正确理解**：看到柱状图，第一件事是看纵轴从哪里开始。如果发现纵轴不从 0 开始，就要在心里重新估算实际的比例关系。

## 本章小结

- 先看数据类型再选图：时间序列用折线图，类别比较用柱状图，两个量的关系用散点图，分布用直方图。
- 柱状图要求纵轴从 0 开始、柱子宽度和间隔一致；折线图要求横轴有顺序、点足够多、不跨越无数据区间连线。
- 散点图能显示两个量的关联，但关联不等于因果。
- 图表会骗人的主要手法有：纵轴截断、纵轴范围不当、横轴间隔不均、用面积或体积表示一维的量。
- 判断一张图是否误导，办法是比较"数据的实际比例"和"图的视觉比例"。
