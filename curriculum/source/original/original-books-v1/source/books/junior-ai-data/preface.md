# 从数据到人工智能 · 前言

## 这本书写给谁

这本书写给初中七到九年级的同学。它假设你已经会写基本的 Python 程序——会用变量、列表、字典、循环和函数。如果这些还不够熟练，建议先读《Python 编程与问题解决》，或者至少把前八章练一遍，因为这本书里的代码会用到它们。

## 读这本书之前，你需要

会写含循环、列表和函数的 Python 程序；理解百分数和平均数；会使用电子表格软件更好（不是必需）。你需要一台能安装 Python 的电脑。书里大部分内容只用 Python 标准库，少数几处需要安装第三方库，书里会明确说明。

## 学习路径

全书十二章，可以分成四段。

**第一段（第 1 到 3 章）：把数据搞到手。** 学习怎么把模糊的疑问改写成可以回答的问题，怎么采集数据（尤其是怎么避免样本偏差），以及怎么清洗数据。这一段看着简单，但它决定了后面所有工作的质量。

**第二段（第 4 到 5 章）：把数据说清楚。** 学习用统计量和图表描述数据。你会发现平均数会骗人，而一张图画对了能比四个数字说得更清楚。

**第三段（第 6 到 10 章）：从数据到模型。** 这是全书的核心。学习怎么选特征和标签、怎么划分训练集和测试集、怎么训练和评估一个分类模型、以及怎么防止数据泄漏。这一段里的每一个概念，在真实的机器学习项目里都要用到。

**第四段（第 11 到 12 章）：负责任地做数据工作。** 学习数据偏差和隐私的问题，最后用一个完整的综合实验把全书串起来。

## 每一章是怎么安排的

每章结构相同。**学习目标**说明要学什么；**开始之前**有一个热身问题；**情景导入**用小故事引出问题；**知识讲解**把概念讲清楚；**详细示例**完整展开两个例子；**动手实践**是你亲手做的事，含步骤、完成判据和排查办法；**常见误区**列出容易搞错的地方；**练习与自测**有六道题；**本章小结**提炼要点；**延伸阅读**给出可进一步查看的来源。

书里的代码都可以直接运行，数据都是自己编的小数据集，可以直接复制使用。少数需要安装第三方库的地方（比如画图），书里会写明需要装什么。

练习题的答案不在正文里，单独放在答案文件中。

## 读完这本书，你能做出什么

你会完成一次属于自己的小数据研究：从提出一个真正的疑问开始，自己设计问卷、收集数据、清洗整理、算出统计量、画图，然后训练一个简单的分类模型并评估它，最后写出一份诚实的报告——包括这个研究的局限和你不确定的地方。

除了这份研究，你会得到几样更重要的东西：一套防坑的检查清单，比如"看到准确率先问数据分布""测试集只能用一次""关联不等于因果"；以及一个习惯——在做任何分析之前，先问清楚"我到底想回答什么问题"。
