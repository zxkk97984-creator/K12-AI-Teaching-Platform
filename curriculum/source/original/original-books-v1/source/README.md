# k12-original-books-v1

一套原创编写的中文 K-12 计算机与人工智能专题教材：6 本书、72 章，覆盖小学、初中、高中三个学段。

本包是**纯数据交付物**，只包含 Markdown 正文、JSON 清单与答案、以及本说明和质量报告。不含代码、脚本、缓存、图片或二进制文件。

## 包内容

```
manifest.json          书目与章节清单（schema: k12.book.source.v1）
quality-report.json    逐章核验结果与已知问题（schema: k12.book.quality.v1）
README.md              本文件
books/<book_id>/preface.md              每本书的前言
books/<book_id>/chapters/01.md ... 12.md  每章正文
answers/<book_id>/01.json ... 12.json     每章答案与评分标准
```

## 六本书

| book_id | 书名 | 学段 | 年级 | 章数 |
| --- | --- | --- | --- | --- |
| primary-computing | 数字世界与计算思维 | 小学 | 1–6 | 12 |
| primary-ai | 和人工智能一起探索 | 小学 | 1–6 | 12 |
| junior-python | Python 编程与问题解决 | 初中 | 7–9 | 12 |
| junior-ai-data | 从数据到人工智能 | 初中 | 7–9 | 12 |
| senior-algorithms | 数据结构与算法实践 | 高中 | 10–12 | 12 |
| senior-ai | 机器学习原理与应用 | 高中 | 10–12 | 12 |

小学两本按一个学段编写（系统稍后映射为低段与高段）。正文以生活语言解释概念，较难的推导与拓展内容放在「挑战一下（小学高段）」下，不要求低段掌握。

## 每章的结构

每章固定包含一个与 manifest 章名一致的一级标题，以及顺序和文字固定的十个二级标题：

学习目标 / 开始之前 / 情景导入 / 知识讲解 / 详细示例 / 动手实践 / 常见误区 / 练习与自测 / 本章小结 / 延伸阅读

每章至少有 4 个知识讲解子节、2 个完整演示案例、1 个含至少 6 个有序步骤的动手活动、3 个常见误区、以及 6 道自测题（Q01–Q02 单选、Q03–Q04 简答、Q05–Q06 实践）。

## 答案文件的用法

答案**不**出现在学生正文中，全部放在 `answers/` 目录下，每章一个 JSON 文件。每个答案对象包含六个字段：`question_id`、`type`、`correct_options`、`reference_answer`、`explanation`、`rubric`。评分标准的分值合计为 10。

## 内容边界

- 全部内容为原创编写，**由 AI 辅助生成，未经教师人工审校**。
- 书中的示例数据均为合成数据，用于说明方法，不具备现实统计意义。
- 所有 Python 示例经实际运行核对输出；数学与统计数值经独立计算核对。
- 书中不宣称任何模型的准确率，所有性能数字都附带了数据、划分方式与阈值的条件。
- 人工智能在书中一律描述为**从数据中学习规律的系统**，不拟人化。

## 已知限制

见 `quality-report.json` 的 `issues` 字段。简要说明：本书的编排顺序和练习难度**没有在真实课堂上验证过**；本包在生成环境中做过完整的格式与数值核验，但教学有效性未经检验。

## 引用与再分发

书中「延伸阅读」列出的链接指向官方文档或权威机构页面（Python 官方文档、scikit-learn、TensorFlow、NIST、OECD 等），用于核对概念。这些链接不代表相关机构对本书内容的认可。

引用本书内容时，请保留「AI 辅助生成、未经人工教学审校」这一说明。
