### 什么是因特网

从硬件看：数以亿计的主机（end systems）通过通信链路和分组交换机连在一起。从服务看：它提供一套编程接口，让分布式应用互相通信。

### 协议

协议定义了收发报文的格式和顺序规则。没有协议，发送方和接收方就无法理解彼此。

### 分组交换

主机把数据切成**分组（packet）**，每个分组带源地址和目的地址，独立转发。交换机收到分组后查转发表，从合适链路发出。这叫**存储转发**。

### 协议分层

| 层 | 功能 | 代表协议 |
|----|------|----------|
| 应用层 | 面向应用 | HTTP、DNS、FTP |
| 运输层 | 端到端传输 | TCP、UDP |
| 网络层 | 路由转发 | IP、ICMP |
| 链路层 | 相邻节点帧 | 以太网、Wi-Fi、ARP |

发送方从上到下层层加头（封装），接收方从下到上层层剥头（解封装）。

### 时延与丢包

分组经过路由器要排队，拥塞时丢包。吞吐率、时延、丢包率是网络三大指标。

## 第2章 应用层

### 网络应用原理

客户-服务器模式：服务器一直在线，客户主动连接。P2P 模式：每个节点既是客户又是服务器。

### Web 与 HTTP

HTTP 是无状态文本协议。请求方法：GET（取资源）、POST（提交）、PUT、DELETE。

```
GET /index.html HTTP/1.1
Host: www.example.com
User-Agent: Mozilla/5.0
Accept: text/html
```

状态码：200 成功、301/302 重定向、304 用缓存、404 未找到、500 服务器错。

Cookie 让 HTTP 有状态：服务器在响应头 `Set-Cookie` 下发标识，浏览器以后每次请求都带上。

### 万维网与文档

HTML 用标签描述结构，CSS 描述样式，JavaScript 提供交互。浏览器渲染引擎把三者画成屏幕上的像素。

### DNS

DNS 是分布式数据库，把域名翻译成 IP。递归查询：浏览器→本地 DNS→根→顶级域→权威，逐级向下。

### CDN

内容分发网把缓存放到离用户近的边缘节点，DNS 根据用户地理位置返回最近节点 IP。

## 第3章 运输层

### 复用与分用

运输层用端口号把数据交给正确的应用。一台主机同时跑浏览器和微信，靠端口区分。

### 无连接的 UDP

UDP 只加源端口、目的端口、长度、校验和，不握手、不重传、不拥塞控制。快但不可靠，适合视频、直播、DNS 查询。

### 可靠的 TCP

TCP 面向连接、字节流、可靠、拥塞控制。

**三次握手**建立连接：客户端 SYN → 服务器 SYN+ACK → 客户端 ACK。

**四次挥手**关闭连接：主动方 FIN → 被动方 ACK → 被动方 FIN → 主动方 ACK。

**序列号与确认**：每个字节编号，接收方确认收到的最高序列号。丢包超时重传。

**流量控制**：接收方告诉发送方自己还能收多少（滑动窗口）。

**拥塞控制**：慢启动（cwnd 指数涨）→拥塞避免（线性涨）→丢包砍半。

## 第4章 网络层：数据平面

### 转发与路由

转发（data plane）：把分组从输入端口搬到输出端口。路由（control plane）：全网计算转发表。

### IP 协议

IPv4 地址 32 位，点分十进制如 `192.168.1.1`。IP 数据报格式：版本、长度、TTL、协议号、源 IP、目的 IP。

### IPv6

IPv6 128 位，解决 IPv4 地址耗尽问题，去掉校验和加速转发，内置 IPsec。

### 路由器工作原理

路由器有输入端口、交换结构、输出端口。查转发表匹配最长前缀。

## 第5章 网络层：控制平面

### 路由算法

链路状态（OSPF）：每台路由器泛洪自己的链路信息，全网有完整拓扑，各自跑 Dijkstra。距离矢量（RIP）：邻居间互传"到各网络的距离"， Bellman-Ford 迭代收敛。

###  BGP

边界网关协议，连接各个自治系统（AS），是互联网的"交通部长"。

### SDN

软件定义网络：把控制逻辑集中到中心控制器，路由器只负责转发。

## 第6章 链路层

### 链路层服务

成帧、差错检测（CRC）、接入链路、MAC 寻址。

### 以太网

MAC 地址 48 位，烧在网卡上。交换机根据 MAC 表转发帧。

### ARP

同一局域网内，把 IP 翻译成 MAC：广播问"谁是 192.168.1.5"，那人单播回答自己的 MAC。

### VLAN

虚拟局域网把一个物理交换机逻辑切成多个隔离网络。

## 第8章 网络安全

### 对称加密与非对称加密

对称加密（AES）：加密解密用同一把密钥，快但密钥分发难。非对称加密（RSA）：公钥加密、私钥解密，解决分发问题但慢。

### 哈希与数字签名

哈希（SHA-256）把任意数据压成定长摘要，不可逆。数字签名：用私钥对摘要签名，任何人用公钥验证，证明内容没被篡改且来自本人。

### HTTPS 握手

浏览器先验证服务器证书（由 CA 签发）→协商会话密钥→之后用对称加密传数据。这就是小锁图标背后的过程。

### 防火墙与入侵检测

防火墙按规则过滤进出流量。入侵检测系统嗅探可疑行为。

## 第9章 多媒体网络

视频流、实时通话（VoIP）需要低时延。DASH 按用户带宽自适应切换视频清晰度。CDN 分发视频。

## 高中阶段补充：数据库 SQL 入门

### 表与查询

关系型数据库用表存数据。`SELECT` 查询：

```sql
SELECT name, score FROM students WHERE score > 80 ORDER BY score DESC;
```

`JOIN` 多表连接：

```sql
SELECT s.name, c.course_name
FROM students s
JOIN enrollments e ON s.id = e.student_id
JOIN courses c ON e.course_id = c.id;
```

`GROUP BY` 聚合：

```sql
SELECT course_id, AVG(score) FROM enrollments GROUP BY course_id;
```

### 索引

B+ 树索引让查询从全表扫描 O(n) 变成 O(log n)。但索引占空间、拖慢写入。

### 事务 ACID

原子性、一致性、隔离性、持久性——数据库出故障也能保证数据不错。
