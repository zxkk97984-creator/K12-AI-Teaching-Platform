## 第1章 引言

机器学习是一门从数据中提炼规律的学科。传统编程是人写规则、计算机算结果；机器学习是反过来——给数据和结果，计算机自己学出规则。

关键组件：数据集（样本）、模型（带参数的函数）、损失函数（衡量预测错多少）、优化算法（调整参数让损失最小）。

机器学习问题分类：

- **监督学习**：每条样本有标签。分类（离散标签，如猫/狗）、回归（连续标签，如房价）。
- **无监督学习**：无标签，聚类、降维、异常检测。
- **强化学习**：智能体与环境交互，通过奖励学习策略。

深度学习是机器学习的子集，用多层神经网络。

### 线性代数直觉

### 自动微分

### 概率

概率衡量不确定性。条件概率 P(A|B)、贝叶斯定理、期望、方差。

## 第3章 线性神经网络

### 线性回归

模型：`y = w·x + b`。损失函数用均方误差 MSE：

L = (1/n) Σ (y_pred - y_true)²

梯度下降：沿梯度反方向调 w、b，步长叫学习率 lr。

```python
import numpy as np

def linear_regression(X, y, lr=0.01, epochs=1000):
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    for _ in range(epochs):
        y_pred = X @ w + b
        dw = (2/n) * X.T @ (y_pred - y)
        db = (2/n) * np.mean(y_pred - y)
        w -= lr * dw
        b -= lr * db
    return w, b

X = np.array([[1.0],[2.0],[3.0],[4.0]])
y = np.array([2.0, 4.0, 6.0, 8.0])
w, b = linear_regression(X, y)
print(w, b)
```

### softmax 回归（多分类）

把输出变成概率分布：`softmax(o)_i = exp(o_i) / Σ exp(o_j)`。损失用交叉熵：`L = -log(y_pred[true])`。

## 第4章 多层感知机

### MLP

在线性层间加非线性激活函数，才能拟合复杂关系。

### 激活函数

| 函数 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| Sigmoid | 1/(1+e^-x) | 输出 0-1 | 梯度消失、非零中心 |
| Tanh | (e^x-e^-x)/(e^x+e^-x) | 零中心 | 仍梯度消失 |
| ReLU | max(0,x) | 计算快、缓解梯度消失 | 负区死亡 |
| Softmax | 归一化指数 | 多分类输出概率 | 只用于输出层 |

```python
def relu(x):
    return np.maximum(0, x)
```

### 欠拟合与过拟合

- 欠拟合：训练集都没学好（模型太简单）。
- 过拟合：训练集好、测试集差（模型太复杂、记住了噪声）。

解决过拟合：更多数据、正则化、Dropout、早停、数据增强。

### 权重衰减（L2 正则化）

损失加一项 `λ/2 · ||w||²`，惩罚大权重，让模型更简单。

### Dropout

训练时随机把一些神经元输出置零，强迫网络不依赖特定神经元。

### 前向传播、反向传播和计算图

前向传播从输入算到输出，记录中间值。反向传播从输出损失往回，用链式法则算每个参数的梯度。

链式法则：`dz/dx = dz/dy · dy/dx`。多层网络就是把这个连乘起来。

## 第6章 卷积神经网络

### 为什么用卷积

全连接层处理图像参数太多（224×224 彩色图 = 15 万输入，第一层 1000 神经元就有 1.5 亿参数）。卷积利用**局部性**和**平移不变性**：小卷积核在图像上滑动，共享参数。

### 卷积操作

卷积核（filter）是个小矩阵（如 3×3），在输入上滑动，对应位置相乘求和，输出特征图。填充（padding）控制输出大小，步幅（stride）控制滑动间隔。

### 汇聚层（池化）

最大池化取 2×2 窗口最大值，缩小尺寸、增强鲁棒性。

### LeNet

LeNet-5（1998）是第一个成功 CNN：卷积→池化→卷积→池化→全连接，用于手写数字识别。

```python
def conv2d(X, K):
    h, w = K.shape
    Y = np.zeros((X.shape[0]-h+1, X.shape[1]-w+1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i+h, j:j+w] * K).sum()
    return Y
```

## 第7章 现代卷积神经网络

- **AlexNet（2012）**：加深网络、用 ReLU、Dropout、GPU 训练，引爆深度学习。
- **VGG**：重复用 3×3 卷积块，结构规整。
- **NiN**：用 1×1 卷积增加通道交互。
- **GoogLeNet**：Inception 并行多尺度卷积。
- **BatchNorm**：每层归一化输入，加速训练、稳定。
- **ResNet（2015）**：残差连接 `y = F(x) + x`，让超深网络（152 层）可训练。这是最重要的创新之一。
- **DenseNet**：每层与所有前层密集连接。

## 第8章 循环神经网络

### 序列模型

文本、语音、时间序列是有序的。RNN 有隐藏状态：`h_t = f(x_t, h_{t-1})`，一步步处理序列。

### 文本预处理

把文本切成词元（token），建词表，转成整数索引。

### RNN 从零实现

```python
def rnn_step(x, h, Wx, Wh, b):
    return np.tanh(x @ Wx + h @ Wh + b)
```

### 通过时间反向传播（BPTT）

把 RNN 按时间展开成深网络，再反向传播。容易梯度消失/爆炸——这就是后来 LSTM/GRU 要解决的问题。

## 第9章 现代循环神经网络

- **GRU**：门控循环单元，用更新门和重置门控制信息流动。
- **LSTM**：长短期记忆，有输入门、遗忘门、输出门和细胞状态，解决长序列梯度消失。
- **双向 RNN**：同时看过去和未来。
- **编码器-解码器**：seq2seq，一个网络编码输入，另一个解码输出，机器翻译基础。
- **束搜索**：生成时不只选最优一个词，保留 top-k 候选。

## 第10章 注意力机制

### 为什么需要注意力

seq2seq 把整句压成一个向量，长句信息丢失。注意力让解码器每步回头看输入的所有位置，动态加权。

### Query、Key、Value

注意力 = 学一个"对齐"权重。Query 是当前要找什么，Key 是每个位置有什么，相似度算出来权重，加权 Value。

### 自注意力与 Transformer

自注意力：序列内部每个词直接和所有词算注意力，不管距离多远。位置编码给词加位置信息。

Transformer（2017，《Attention Is All You Need》）完全抛弃 RNN/CNN，只用自注意力 + 前馈网络，并行训练快、长距离依赖强。这是今天所有大语言模型的基础。

## 第11章 优化算法

- **SGD**：随机梯度下降，每次一个小批量。
- **动量法**：积累历史梯度，冲过局部坑。
- **AdaGrad/RMSProp**：自适应学习率。
- **Adam**：动量 + RMSProp，最常用。
- **学习率调度**：训练中途调小学习率。

## 高中阶段补充：大语言模型与 AI 伦理

### 大语言模型（LLM）

Token：文本切分成最小单位（可以是字、词、子词）。参数量：模型里可训练的权重数（GPT-3 有 1750 亿）。预训练：在海量文本上预测下一个词；微调：在特定任务数据上再训练。对齐（RLHF）：用人类反馈让模型输出更符合人类偏好。

LLM 能做：问答、翻译、写作、写代码。不能做：保证事实正确（幻觉）、实时信息、精确计算。

### AI 伦理

- **偏见**：训练数据有偏见，模型放大偏见。
- **隐私**：训练数据可能含个人信息。
- **版权**：训练数据版权争议。
- **可解释性**：深度网络是黑盒。
- **AI 生成内容标识**：建议标注 AI 生成。

### 大数据与云计算

Hadoop/MapReduce 分布式处理超大数据；Spark 内存计算更快。Docker 容器封装环境；微服务把大应用拆成小服务；云是按需租用的计算资源。
