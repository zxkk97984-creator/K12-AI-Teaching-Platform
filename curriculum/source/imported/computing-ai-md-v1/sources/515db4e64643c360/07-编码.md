## 第1章 最好的朋友（电筒密谈）

两个小孩在夜里用电筒闪烁传递消息。闪烁本身就是一种"编码"：长亮、短灭代表不同含义。这一章奠定全书基调——**编码就是用两种状态的组合来表示信息**。

## 第2章 编码与组合

Morse 码用点和划的不同组合表示字母。短码给常用字母（E 是一个点），长码给生僻字母——这就是变长编码思想的萌芽。

## 第3章 布莱叶盲文与二元编码

盲文用 6 个位置的凸点有无来编码，每个位置两种状态（有/无），2⁶=64 种组合足够表示字母数字。这是纯二元编码的直观例子。

## 第4章 手电筒的剖析

拆开手电筒，看到电池、灯泡、开关、导线。电路通断就是最基本的开关模型。

## 第5章 绕过拐角的通信

用电报把信号传得更远。继电器（relay）用小电流控制大电流开关，让信号可以中继放大。

## 第6章 逻辑与开关

把开关串联就是 AND（两个都按灯才亮），并联就是 OR（按任一个灯就亮）。**布尔代数**和电路开关从此等价。

```python
def AND(a, b):
    return a and b
def OR(a, b):
    return a or b
def NOT(a):
    return not a
```

## 第7章 电报与继电器

电报网用继电器自动转发信号。继电器本身就是个电磁开关，可以被电控制来控制其他电路——这是**逻辑门**的硬件基础。

## 第8章 从十进制开始

我们用十进制是因为有十个手指。但任何进制都能表示同一个数。

## 第9章 其他进位制

二进制只有 0 和 1，正好对应电路的通和断。八进制、十六进制是二进制的简写。

| 十进制 | 二进制 | 十六进制 |
|--------|--------|----------|
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |
| 9 | 1001 | 9 |
| 10 | 1010 | A |
| 15 | 1111 | F |
| 16 | 10000 | 10 |

## 第10章 比特与比特

一个开关是 1 bit（binary digit）。8 bit = 1 byte。n 个开关能表示 2ⁿ 种状态。

## 第11章 字节与十六进制

一个字节 8 位，范围 0~255。十六进制每位对应 4 个二进制位，写起来紧凑。

## 第12章 从ASCII到Unicode

ASCII 用 7 位表示 128 个字符（英文字母数字标点）。Unicode 覆盖全世界文字，UTF-8 变长编码兼容 ASCII。

## 第13章 用逻辑门做加法

半加器（half adder）：两个 bit 相加，和 = XOR，进位 = AND。全加器把进位也加进来。把 8 个全加器串起来就是 8 位加法器。

```python
def half_adder(a, b):
    s = a ^ b
    c = a & b
    return s, c

def full_adder(a, b, cin):
    s1, c1 = half_adder(a, b)
    s2, c2 = half_adder(s1, cin)
    return s2, c1 | c2
```

## 第14章 减法呢？

用补码（two's complement）把减法变成加法。负数 = 正数取反加一。这样加法器电路就能同时做加减。

## 第15章 反馈与触发器

把两个非门的输出交叉反馈，就做成了**锁存器（latch）**——能记住 1 bit。再加上时钟控制就是触发器（flip-flop），这是存储器的基本单元。

## 第16章 组装存储器

把很多触发器按地址排列，加上地址译码器，就是随机访问存储器（RAM）。n 位地址能访问 2ⁿ 个存储单元。

## 第17章 自动化

把程序指令存在存储器里，CPU 自动一条接一条取指译码执行——这就是**冯·诺依曼结构**。指令周期：取指→译码→执行，循环往复。

## 第18章 从算盘到芯片

计算工具的历史：算盘→机械计算器→继电器计算机→电子管→晶体管→集成电路→微处理器。摩尔定律：晶体管数每 18-24 个月翻一番。

## 第19章 两个经典微处理器

8080 和 6502 是早期微处理器。它们都从内存取指令，指令分为数据传送、算术运算、跳转控制三类。理解了它们就理解了现代 CPU 的祖先。

## 高中阶段补充：操作系统与组成原理深化

### 指令周期

CPU 每秒重复几十亿次：PC（程序计数器）指向指令地址→取指→译码→执行→PC+1。

### 缓存与多核

CPU 比内存快几百倍，中间放 L1/L2/L3 缓存。数组连续存储命中缓存，链表散乱分布频繁不命中——这就是数组遍历比链表快一个数量级的硬件原因。

### 进程与线程

进程是运行中的程序，独立内存；线程是进程内执行单元，共享内存。GIL 让 Python 多线程不能真正并行 CPU 任务。

### 虚拟内存与分页

每个进程有私有虚拟地址空间，MMU 翻译成物理地址。内存不够时把页换到磁盘（swap）。

### 文件系统

inode 存文件元数据和数据块位置，文件名存在目录里。删除文件只是标记块可用，数据还在直到被覆盖。
