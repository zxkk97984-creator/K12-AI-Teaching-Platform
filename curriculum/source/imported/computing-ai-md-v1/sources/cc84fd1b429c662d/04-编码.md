### 第 1—2 章 编码与组合

"编码"就是用一种符号代表另一种东西。红绿灯：红=停、绿=行。摩尔斯电码：点和横代表字母。编码的本质是"约定"——双方提前说好什么符号代表什么意思。

组合是编码的基础。2 个灯泡，每个有亮/灭两种状态，就能表示 4 种信号：灭灭、灭亮、亮灭、亮亮。灯泡越多，能表示的东西越多。3 个灯泡能表示 8 种，4 个灯泡能表示 16 种。这就是二进制的雏形。

### 第 3 章 布莱叶盲文与二元编码

盲文用凸起点的位置编码字母。6 个位置，每个凸或不凸，能表示 64 种组合——够排下所有字母和标点。这就是二元编码：每个位置只有两种状态（凸/平），组合起来就能表示任意符号。

### 第 4—5 章 手电筒与绕过拐角的通信

两个人隔院子打手势：手电筒亮一下=A，亮两下=B。这就是最原始的通信。问题是拐弯了看不见怎么办？答案是"中继"——派第三个人站在拐角处，看到信号就转给下一个人。这就是网络里"路由器"的雏形。

### 第 6—8 章 逻辑与开关、继电器与门电路

这是全书最核心的部分。开关串联 = 与门（两个都按下才亮）；开关并联 = 或门（按任意一个就亮）；按下去灯反而灭 = 非门。

- **与门**：两个开关串联，必须都按下灯才亮。
- **或门**：两个开关并联，按任意一个灯就亮。
- **非门**：开关一按，灯反而灭了。

用这些"门"电路，就能搭出加法器——把两个二进制数加起来。这就是"电路能算数学"的起点。电脑本质上就是几亿个开关在疯狂开合。

### 第 9—11 章 我们的十进制、其他进制、一位一位

我们平时用十进制（逢十进一），但电脑只有两种状态（0 和 1），所以电脑用二进制。

十进制转二进制：不断除 2 取余数。比如 13：13÷2=6 余 1，6÷2=3 余 0，3÷2=1 余 1，1÷2=0 余 1，从下往上读就是 1101。

```python
print(bin(13))
```

电脑里一个数就是一串 0 和 1。8 个 0/1 叫一个字节（Byte），能表示 256 个数。

### 第 12 章 字节与十六进制

二进制写起来太长（一个字母就要 8 位）。十六进制（逢十六进一）是二进制的"缩写"：一位十六进制 = 四位二进制。比如 `1101` 写成 `D`。

```python
print(hex(13))
```

### 第 13 章 从 ASCII 到 Unicode

电脑里存文字，本质是存数字。ASCII 表给每个英文字母、数字、标点分配一个编号（A=65，a=97，0=48）。但 ASCII 只有 128 个符号，不够用——中文一个字就上万个。

Unicode 给全世界每个字符都分配一个唯一编号，包括中文、 emoji、阿拉伯文。UTF-8 是 Unicode 的一种存储方式，英文占 1 字节，中文占 3 字节。这就是为什么你的 Python 文件要写 `encoding="utf-8"`，不然中文会乱码。

```python
print(ord("A"))
print(ord("中"))
print(chr(65))
print(chr(20013))
```

### 第 17—18 章 触发器与时钟

用逻辑门能搭出"触发器"——一种能记住一个比特的电路。有了触发器，电脑就能"存东西"了。把几十亿个触发器排在一起，就是内存。

时钟就是一个不断 0101 振荡的电路，它指挥电脑"下一步、下一步"地走。CPU 的主频（比如 3 GHz）就是每秒振荡 30 亿次。

### 第 19 章 存储器组织

内存就是一排触发器，每个存一个 0 或 1。为了找到某个数据，给每个位置编号（地址）。CPU 要数据时，报地址，内存就把那个位置的数据送过来。

### 第 21 章 算术逻辑单元（ALU）

ALU 是 CPU 里真正做加减乘除的部件。它用前面讲的加法器搭出来。加法器用与门、或门、非门一层层搭，最终实现两个数相加。

### 第 22—23 章 寄存器与总线、CPU 控制信号

CPU 内部有很多小存储叫寄存器（比内存快得多）。总线是连接 CPU、内存、硬盘的"高速公路"，数据在上面跑来跑去。CPU 控制信号就是指挥总线"现在听谁的、读还是写"。

### 第 27 章 编码：汇编语言

最早的程序就是一堆 0 和 1（机器语言），人根本读不懂。后来发明了汇编语言：用 `MOV`、`ADD` 这种英文单词代替二进制指令，再由一个程序翻译成机器语言。这就是编程语言演化的起点。

### 第 28 章 操作系统

操作系统（Windows、macOS、Android）是大管家：管理文件、管理内存、管理屏幕、管理键盘鼠标。你写的 Python 程序，其实是通过操作系统间接操控硬件。
