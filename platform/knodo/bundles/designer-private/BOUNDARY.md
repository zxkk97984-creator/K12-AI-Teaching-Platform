# Designer 私有资料边界（书面清单）

本文件规定哪些内容只能停留在服务端/Designer 会话，**永远不进入** Tutor 共享资料、课堂 bundle 或学生可见投影。

## 1. 只允许 Designer 会话处理（服务端私有）

| 内容 | 说明 |
|---|---|
| 标准答案 / 正确选项 key | 题稿 `answer` 字段；仅后端保存，用于判分 |
| 解析（explanation） | 讲解为什么；学生只有在业务允许时才看到分层提示/解析 |
| 隐藏测试 / 参考解 | 代码任务的 `hidden_tests`、`reference_solution` |
| 三级提示全文 | 提示逐级发放，不整包下发 |
| 聚合误区摘要 | 只能是去身份化的聚合信息 |

## 2. 禁止进入 Designer 的内容

- 真实学生身份、联系方式、学校等个人信息；
- 完整学生聊天记录与其他学生会话；
- 平台密钥、PAT、`.env`、环境变量；
- 未授权的外部素材或题库原文。

## 3. 与学生可见面的分离规则（QA16）

1. Designer 返回的题稿 JSON 中，`answer`/`explanation` 属于私有字段，只由本地后端读取；
2. 学生端只接收由后端生成的**投影**（题干、选项、允许的提示层次），投影中不得出现答案或解析；
3. 题稿会话与 Tutor 学生会话物理分开，题稿整体不允许转发到学生通道；
4. 本仓库的自动校验（`scripts/package-knodo.py verify`）会检查样例的学生可见投影不含答案文本。

## 4. 本发布实际包含的私有素材

`included_in_this_release: []` —— T09 只交付边界与打包规则，未把任何答案类素材打包进发布目录。
