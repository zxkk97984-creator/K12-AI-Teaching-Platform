# 比赛演示脚本

## 准备

首次执行 `./k12 setup`，之后用 `./k12 start --build` 启动，使用 `./k12 status` 确认服务。
需要编程执行时改用 `./k12 setup --with-runner` 和 `./k12 start --with-runner`。
已有开发服务可直接复用，不必重复初始化。

准备专用演示账号、已发布课程、互动内容和练习。按现场网络选择真实 Knodo 或离线 fixture，
明确说明当前模式。学生登录后进入 `/workbench`，管理员进入 `/admin/resources`；
未完成首次设置的学生先选择年级。账号配置见[本地开发说明](../operations/LOCAL_DEV.md)。

语音使用日常 Edge 或 Chrome。在学习设置启用输入和输出、选择普通话声音，先试读一句并说一句合成问题；识别后修改草稿，再手动发送。自动读新回复需另行开启，默认关闭。现场没有声音或权限被拒绝时，使用键盘和讲解文字，明确说明实际状态。

## 建议演示顺序

1. 展示学习首页，再从 `/settings` 更换具体年级，说明小学低段、小学高段、初中、高中的首页与导航差异。保存昵称、教师风格或桌宠，刷新确认账号设置保留。
2. 从 `/resources` 或 `/study` 打开资料、课程、书架和阅读历史。小学可展示绘本续读；教材阅读可展示目录跳转和“问问老师”，再展开、收起一道固定自测题的参考答案；说明这里不做在线判分。
3. 打开 `/conversations`，不选课程直接提问，再切换历史会话。分别使用小学、初中、高中演示账号，展示对应教师名称和讲解风格；小学低段和高段共用小学教师。展示桌宠中的轻量提问与完整对话页；输入“查课程、本人错题和学习进度”，查看查询时间并点击结果卡片。语音是否可用以当前浏览器能力和权限为准。
4. 从内容页提问，说明老师会收到发送时的页面上下文。需要课堂流程时进入 `/study/lesson`，演示讲解、检查、暂停恢复，再点击课堂“开始练习”。小学也会进入该章的老师练习；作答后回到同一课堂，复盘并明确完成，刷新确认恢复。
5. 小学从 `/animations` 或 `/practice` 进入已发布的互动讲解或小游戏；初高中从 `/activities` 进入互动探索。十二份讲解自然结束后显示“已看完”，继续“自己试一试”、保存、刷新确认实验输入恢复；已看完不代表掌握或成绩。小游戏另按原有完成规则演示，保存失败时展示重试。
6. 从教师回复生成练习，或在 `/practice` 选择章节生成。小学先选“老师给我的练习”。展示现有单选、判断和排序，答题、查看提示和服务器结果，再提问“查本人错题和学习进度”，点击卡片回到对应练习；生成失败如实展示，不能用示例题冒充实时生成。
7. 初高中进入 `/code`，展示各学段 6 道题的搜索、筛选、收藏和历史。保存草稿后运行公开示例，再提交正式判题；公开示例不产生分数，正式成绩来自 runner 的可信用例，AI 建议不改变成绩。
8. 在聊天中明确说“我喜欢观察星星，希望用生活例子讲解”。进入 `/growth` 查看整理进度，等待自动条目及来源出现；新建会话提问，让教师结合兴趣举例。可切换年级后新建会话，说明教师共享同一账号的记忆。更正兴趣后再次提问，再执行遗忘并确认后续上下文不再使用该条目。整理失败如实展示并重试，不把 fixture 提取冒充真实模型结果。
9. 在 `/growth` 展示手写 Markdown 的编辑、预览和版本恢复，以及分类搜索、自动整理／聊天使用记忆两个开关、主动整理历史聊天、删除聊天时的保留／遗忘选项。手写内容不会被自动总结覆盖。
10. 管理员打开 `/admin/ai`，展示教师、四学段映射、能力登记、远端核验和合成协议测试。调整路由后新建会话即可生效；已有会话保留教师快照。再展示 `/admin/resources/interactive` 导入发布。课程编排和教学包生成已从常规入口隐藏；需要查看已有教学包时，使用原 `/admin/authoring?job=…` 地址，不把历史结果当成本次生成。

## 答辩重点

- 四学段界面围绕同一账号、课程版本和学习记录展开，切换页面后保留学习过程。
- 三位教师负责教学互动和编程反馈，Designer 负责教研草稿，内部记忆助手返回结构化提取建议；身份、记忆合并、成绩和数据归属由本地服务处理，助手之间不自行派工。
- 互动包在受限播放器中运行；普通 HTML 的自报结果与服务器判分、可信 runner 结果分别介绍。
- 个人记忆按学生隔离，后台整理不阻塞聊天；人工更正优先，遗忘抑制旧消息重新记住。它是带来源的教学参考，不能替代测验成绩或推断人格与能力。
- 真实 Knodo、fixture、浏览器合成测试和历史评测分开说明，不推断未经验证的学习效果。

完整操作与内容规范见[本地开发说明](../operations/LOCAL_DEV.md)和[互动内容接入说明](../operations/INTERACTIVE_CONTENT.md)。
