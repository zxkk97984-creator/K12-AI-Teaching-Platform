# ADR-005：知识发布与数据权威

状态：ACCEPTED  
日期：2026-09-18

## 决策

- 课程正文、题目快照、答案/隐藏测试、学习事件、成绩、权限和发布状态以本地 PostgreSQL/版本化文件为权威。
- Knodo 知识包只导出学生可见正文、目标、受控资源清单和来源定位；不导出标准答案、隐藏测试、真实学习数据或 `.env`。
- 不自研向量库/embedding 运行层；需要选取上下文时先由后端按章节、年级、权限和 revision 构造受控上下文。平台知识检索只有在租户实测后才可补充。
- 资源发布状态与真实文件 hash 绑定；平台生成的内容先进入草稿，不能直接进入发布目录。

## 原因

课程版权、学生数据、答案隔离和课程版本具有业务后果，不能交给模型自证或远端会话状态决定。
