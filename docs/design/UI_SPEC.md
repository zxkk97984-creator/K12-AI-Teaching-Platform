# 霜铃 K12 · 教学工作台 UI 规范 v1（T07）

日期：2026-09-18

## 0. 依据（不编造视觉）

| 依据 | 位置 | 用途 |

## 1. 导航

- 主导航五项：`学习`（当前工作台）、`课程`、`练习`、`成长`、`设置`。
- 本卡只接通 `学习` 与 `设置`（T05 已存在）；`课程/练习/成长` 在导航中渲染为**禁用项**并给出原因（`T08/…`），不生成可点击死链。
- 管理员：`/workbench` 显示管理端说明面板，不显示学生工作台；管理能力（课程审校/资源/任务）属 T22，本卡不提供入口，也不提供批量用户管理。
- 章节导航（左栏）：题目所述章节树来自 T08 内容接口，本卡显示**未接通**空态；任何情况下都不出现演示用的假章节。

## 4. 组件

| 组件 | 位置 | 规则 |
|---|---|---|
| `Button` 语义 | 现有 `.secondary` + 新增 `.ghost`/`.danger-ghost` | 最小高度 44px（宽敞模式 52–56px）；`disabled` 必须给出原因文案，不单独灰掉 |
| `StatePanel` | `frontend/src/shared/ui/state.tsx` | 四种状态：`loading`（`role="status"` + `aria-live="polite"`）、`empty`、`error`（`role="alert"`）、`disabled`；都包含标题+说明+可选动作 |
| 表单 | 现有 `input/select/label` 样式 | 标签始终可见（不用 placeholder 代替标签）；错误信息紧邻字段 |
| 工作台三区 | `frontend/src/features/workbench/` | 章节导航 / 学习画布 / 教师区 / 当前活动槽位，四个区域在有数据后仍保持同样的位置 |
| 分段切换 | 窄屏 `role="tablist"`（内容·教师·活动） | 支持 ←/→/Home/End 键；`aria-selected`；焦点环可见 |

## 5. 响应式

| 视口 | 结构 |
|---|---|
| ≥1024px | 三列：章节导航（240px，可收起）+ 学习画布（1fr）+ 教师区（320px）；当前活动槽位固定在画布顶部 |
| 820px | 单列 + 顶部分段切换（内容/教师/活动）；章节导航通过“章节”按钮以覆盖层打开，不挤压画布 |
| 390px | 同 820 结构；按钮全宽、字号不缩小到 16px 以下；代码/表格区域将来只允许**区域内部**横向滚动 |

验收口径：`document.documentElement.scrollWidth <= innerWidth + 1`（无整页横向溢出）、无元素重叠、主要操作在首屏可达。

## 6. 学段密度（低龄不只是换色）

`data-density="spacious"`（PRIMARY_LOWER / PRIMARY_UPPER）：

- 控件最小高度 ≥52px、行高与正文字号上调一档、卡片间距加大；
- 首屏同时出现的动作更少：章节导航默认收起、画布只显示“本课目标”与一个下一步提示，不并排堆叠资料/统计；
- 文案保持短句（由后续内容任务保证），本卡只保证布局与控件尺度。

`data-density="compact"`（JUNIOR / SENIOR）：更紧凑的间距、更多同屏信息（目标 + 先备知识 + 资料位）。

两类密度共用同一 DOM 结构，只通过 token 与少量条件渲染调整，不做两套页面。

## 7. 状态与文案规则（反假数据）

1. **loading**：真实请求进行中才出现，文案“正在读取学习档案…”。
2. **empty**：接口成功但没有数据时出现；本卡用于“课程目录尚未接通”。
3. **error**：区分 401（跳转登录）与 503/其他（显示错误信封的 message 与 request_id，提供真实重试）；不显示假课程内容。
4. **disabled**：能力尚未实现时出现，必须写明**归属任务**（如“课程目录：T08”“教师：T10/T12”“活动：T14”）。
5. 禁止：写死学习天数/正确率/连续天数、假教师回复、假“保存成功”、把 fixture 数据当正式数据。
6. 教师区在 Knodo 未接通时显示“教师未启用”，不含任何气泡或“正在生成”字样（QA38 语义）。
