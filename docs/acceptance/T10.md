## 5. 失败与修复（保留证据，不删断言）

1. **条件分支校验被静默绕过（真实缺陷）**：`Annotated[Model, AfterValidator]` 的属性转发使
   `model.model_validate()` 落到内层类，`allOf/if/then/else`（Designer 的 quiz/lesson 分支）未生效。
   由 `test_designer_operation_branch_is_enforced` 捕获；改为 **TypeAdapter 校验 + 模型实例转 dict**
   后两方向均正确拒绝。回归：该用例 + 44 项差分用例。
2. **`number` 类型未支持**：`lesson-package-draft` 的动画参数使用 JSON `number`；构建器 fail-loud 直接报错
   （证明"未知关键字必响"的护栏有效）。已补 `StrictInt | StrictFloat`（排除 bool）。

   改用契约内 `NEEDS_HUMAN_REVIEW` / `INSUFFICIENT_SOURCE`。
4. **新增文件 lint/格式**：ruff 报 23 项 + 7 文件待格式化，已在本卡文件内修复（全仓 ruff 现为 clean）。
5. **健康检查用例两次"失败"实为环境前置**：`test_ready_uses_isolated_test_database` 依赖
   `APP_ENV=test`（check.sh 会导出）；我的临时命令漏导出时复现 503，导出后 3 passed。
   已记入报告，未改任何测试或断言。
