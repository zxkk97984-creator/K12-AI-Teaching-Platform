## 5. 失败与修复（真实缺陷，证据保留）

1. **并发幂等**：用 savepoint 捕获唯一冲突时，冲突在 `COMMIT` 才出现，第二个请求 500。
   改为 **`INSERT … ON CONFLICT (owner, key) DO NOTHING RETURNING id`**：数据库裁决，输家零写入并重放既有 run。
2. **过期租约路径的同步 IO 崩溃**：`finalize_run` 在读状态前先 `rollback()`，SQLAlchemy 实例过期后
   `run.status` 触发同步懒加载（MissingGreenlet）。改为**先取值再回滚**（并保留 `populate_existing` + 防御性 refresh）。
3. **会话详情 500**：`SessionSummary` 漏传 `grade`。已补并加回归（历史用例覆盖）。
4. **dev fixture 延迟不生效**：T10 fixture 仅在 DELAY 场景等待，worker 原来传 `delay_seconds` 但用 SUCCESS 场景。
   现按 `teaching_fixture_delay_seconds > 0 && gateway_mode == fixture` 选择 **DELAY 场景**（仅 dev/e2e，默认 0）。
5. **SSE 关闭语义**：终态 `source.close()` 后浏览器仍触发 `onerror`，页面误报"连接中断"并抖动。
   加 `finished` 标志：终态后不再报错。另把消息区改为**固定高度可滚动**，消除取消按钮的布局漂移。
6. **check.sh source-audit 腿外部阻塞**：`CareerMate` 工作区有外部改动（10 个已修改文件 + 新增 `src/test/bin-path.ts`，
   HEAD 未变 `724c00f9…`），`validate_source_audit.py` 报 `status entries changed / untracked paths changed`。
   与本卡无关，不修改旧仓库；项目腿逐条实跑全绿（§3）。已在提交时向 A 标注。
7. **迁移测试期望**：旧断言把 head 固定为 `0004_content_reading_events`；T12 合法推进 head，已更新为
   `0005_teaching_runs` 并新增 4 张表 + 5 个新约束断言（不是放宽断言）。
