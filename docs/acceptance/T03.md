## 冻结边界

- `TEACH_TURN`/`CODE_FEEDBACK` 由 Tutor 处理；`QUIZ_DRAFT`/`LESSON_PACKAGE_DRAFT` 由 Designer 处理。
- `COMPLETED` 不能由模型输出写入；课程完成、成绩、权限和审核由本地可信服务决定。
- 来源必须匹配本轮 `(source_id, revision, locator)`，动作必须在服务端允许集合中，资源/任务必须已发布且适龄。
- 删除或改变 owner、revision、幂等或过期状态的结果标记为拒绝或 `STALE`，不覆盖新事实。
- 本地 JSON 只约束业务语义，不是 Knodo HTTP 请求/响应。
