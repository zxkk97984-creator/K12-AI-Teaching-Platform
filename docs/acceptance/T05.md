## 2. 实际变更

### 后端身份

- 新增 `backend/app/modules/identity/`：用户、可撤销会话、学生/管理员依赖、Argon2id 密码、四档 stage、可空 grade、偏好、登录限流和幂等 demo provisioning。
- `auth_sessions` 只存 SHA-256 token hash、user、created/last_seen/expires/revoked；真实原始会话令牌只在 HttpOnly `sl_session` Cookie。
- 会话登录接受服务端生成的 token；客户端预设 `sl_session` 不参与认证。登出会同时撤销服务端会话和清除 Cookie。
- 新增 `backend/alembic/versions/0001_identity.py` 和 `0002_identity_constraints.py`：身份表、级联关系及数据库级枚举/年级/用户名/JSON数组/SHA-256 形状约束。
- 新增身份 OpenAPI：`contracts/openapi.identity.json`；前端类型由 `openapi-typescript` 生成到 `frontend/src/shared/types/generated/identity.ts`。

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/auth/csrf` | 设置 `sl_csrf` 非 HttpOnly 双提交 Cookie并返回 token |
| POST | `/api/v1/auth/login` | 需要精确 Origin + CSRF；成功后签发新会话 |
| POST | `/api/v1/auth/logout` | 需要精确 Origin + CSRF；撤销当前会话 |
| GET | `/api/v1/me` | 只返回服务端会话对应的本人 |
| PATCH | `/api/v1/me/profile` | stage/grade，必须有 `base_revision` |
| PATCH | `/api/v1/me/preferences` | 讲解风格、兴趣、主动引导、语音偏好，必须有 `base_revision` |
| GET | `/api/v1/admin/identity/status` | 管理员角色专用，仅返回计数和能力状态，不返回用户明细 |

所有写请求强制 `Origin` 精确匹配、`X-CSRF-Token` 与 `sl_csrf` 双提交一致；缺失或恶意 Origin、错误/缺失 CSRF 均 403。`GET /me` 不读取客户端传入的 `user_id`，PATCH 的额外身份/权限字段被 422 拒绝。

- 偏好字段：`preferred_style`、`interests`、`proactive_guidance_enabled`、`voice_preference`。语音偏好只记录意图，界面明确显示当前语音能力尚未验证/启用。
- PATCH 只更新提交字段；`profile_revision` 单调递增，旧版本返回 409，不覆盖新数据。
