## 5. 失败与修复（真实缺陷，证据保留）

1. **路由未注册**：链式命令短路导致 `app/main.py` 未写入 quiz 路由，测试全部 404。修复：重新打补丁并**验证** `grep quiz_router` 后再跑。
2. **重放被终态挡住（真实行为缺陷）**：一题测验答完即 COMPLETED，之后同键重放返回 409 —— 网络重试拿不到原结果。修复：`submit_answer`/`request_hint` **先查幂等键**，命中且 payload 一致即返回存储结果（终态检查只对新作答生效）。
3. **MissingGreenlet（实现）**：重放分支 `await db.rollback()` 使 `session.status` 失效，返回时读属性触发同步 IO。修复：rollback 前捕获标量，并把**只读**重放分支改为 `commit()`（不使其失效）。
4. **MissingGreenlet（测试侧）**：测试会话 `rollback()` 使已加载 ORM 属性失效。修复：测试内 19 处 `rollback()` → `commit()`（`expire_on_commit=False` 保持属性），触发器异常后仍用 rollback；并提前捕获 `chapter_id` 等标量。
5. **迁移断言写错**：把唯一约束名放进 CHECK 列表。修复：仅断言真实 CHECK 约束。
6. **语义澄清**：排序题提交缺项（`["A","B"]`）属结构性错误 → 422（在 attempt 上限检查之前）；合法但超次 → 409。已在测试中固定两种行为。
