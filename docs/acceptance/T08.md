## 5. 首次失败与修复（保留）

1. 后端测试首轮 11 失败：所有 content 写接口都走 T05 中间件，测试未带 Origin+CSRF → 403。修复：测试统一使用真实 `Origin + X-CSRF-Token`；同时**保留**一个故意不带 CSRF 的负例（该负例一度被批量替换误伤成 200，已恢复为预期 403）。
2. T06 可见性回归用例把“旧版正文未变”比较成整块 JSON，新增 `block_id` 后失败。修复：比较前剔除 `block_id`，**语义断言（旧版 body 未变）未削弱**。
3. “DTO 不泄露答案/隐藏测试”最初用字符串包含判断，误伤课文里合法出现的变量名 `answer`。修复：改为遍历 DTO 键名断言不存在 `answer/answers/hidden_tests/solution/reference_solution/original_sha256/release_key/review_comment/source_manifest`。
4. 一个用例忘了导入 legacy 包导致 `revision_by_slug` 为空；补齐导入。
5. `ruff`：迁移/模型长行、router 的 `B904`、测试未用导入 → 逐项修复（不关闭规则）。
6. 前端单测首轮 4 失败：API client 用例错误地测了被 mock 的函数 → 拆出 `api.test.ts` 测真实实现；标题重复导致 `getByRole` 命中两处 → 用 `level` 区分；随后 404/401 用例的 mock 次数与调用次数不匹配 → 改为显式捕获错误对象断言。
