## 续作：最小应用边界与真实本地闭环

依据目标文件允许“为完成必要验收补充最小接口/迁移”的规则，本轮没有另起一套身份或
执行架构，而是在既有 T23/T24/T25 边界上补齐最小应用面：

- `codelab_code_drafts` 和 `codelab_code_runs` 使用当前 identity owner、不可变 task revision、
  lesson session 可选绑定、代码 SHA-256 快照和 owner+幂等键唯一约束；迁移为 `0015_codelab_runs`。
- `/api/v1/code-tasks`、draft GET/PUT、`/api/v1/code-runs`、run GET/cancel 和
  `/api/v1/code-runs/{id}/feedback` 均经过既有 session/CSRF；跨 owner 只能得到自己的草稿/运行。
- FastAPI 只调用 loopback runner control plane；runner 继续持有 Docker 权限，无法用无 Docker
  的宿主执行冒充成功。未配置 runner 明确返回 `UNAVAILABLE`；fixture 反馈不写分数、不覆盖可信判分。
- 前端使用真实 CodeMirror Python editor，支持草稿保存/刷新恢复、运行结果、错误修正和反馈状态；
  CodeLab 以 lazy route 接入，不改变已有课程/身份入口。
