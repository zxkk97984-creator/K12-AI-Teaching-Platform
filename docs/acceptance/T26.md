## 核对结果

T24 已有真实 Docker runner，T25 已有可信 grading/feedback 快照边界，但当前新项目没有
CodeLab 的应用边界：

- 没有 `/api/v1/code-tasks`、`/api/v1/code-runs`、`/api/v1/code-runs/{id}/feedback` 路由；
- 没有持久 code-run/code-draft 模型、owner/lesson_session 绑定、取消/幂等 API 或可供前端
  查询的 DTO；
- T25 的快照/feedback 目前是可信侧纯函数，不是 HTTP 可调用的数据源；
- 前端尚未安装 CodeMirror，T26 允许修改范围也不包含新增依赖的 `package.json`/lockfile；
- 当前 T26 白名单只允许 `frontend/src/features/codelab/`、`frontend/src/pages/code/`、
  `backend/app/modules/learning/`、`frontend/e2e/`、`backend/tests/`，不足以在正确边界新增
  codelab router、模型、迁移和 OpenAPI。

## 不能伪造的部分

在缺少上述应用/API边界时，新增一个前端 localStorage/mock 页面只能显示假运行结果，无法满足
QA27 的真实 Docker run、QA14 的跨账号 owner 隔离、QA31 的 runner unavailable 状态和“回本章
写真实 code event”要求。因此本轮没有添加假 CodeMirror、假成功按钮、前端 eval 或 fixture
run 记录，也没有把 T24/T25 单测误报为浏览器端到端通过。
