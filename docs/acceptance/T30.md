## 首次失败与修复

首轮浏览器为 19 passed/3 failed：

1. resources 使用相对 fixture 路径，Playwright 从仓库根运行时找不到文件；改为
   `resolve(process.cwd(), "backend/tests/fixtures/t20")`，并使用唯一 run slug/title，避免重跑
   把旧资源的“已存在”误当上传成功。
2. learn/growth 复用了已经被前序浏览器用例改变的账户；新增专用合成账号并让 growth 使用
   `E2E_GROWTH_STUDENT`，保证 cold-start/candidate 断言来自 fresh owner 状态。
3. animation 发现真实页面只有“当前学段没有已发布动画”：T21 后端测试会显式记录 human review
   再发布 senior chapter，但本轮没有人审授权。用例现在先断言诚实空态再显式 skip，不伪造
   picker 或控制器通过。
4. e2e 截图原先指向旧 `.herdr-control` 或相对仓库外路径；统一改为本轮 acceptance evidence
   路径，旧恢复目录不再写入。
