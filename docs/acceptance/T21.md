## 5. 首次失败与修复（真实记录，未改断言骗绿）

1. **e2e 区间宽度断言写错**：把「候选区间：3~6；中间位置：4」里的中间位置当成区间上界，得到 width=62。修复为按 `候选区间：(\d+)~(\d+)` 精确提取。
2. **e2e 不变量过严**：最初要求每一步区间都严格变小，但 `PROBE` 步在**同一区间内**比较（设计如此），会与上一步等宽。改为「单调不增 + 末值严格小于首值」，并在报告写明这是算法的真实形状。
3. **e2e 模板串场**：未排序输入反例后直接填排序数组，却仍在二分模板下 → 客户端按前提正确拒绝、没有播放器。修复为显式切回排序模板（**保留**二分拒绝的断言）。
4. **后端缺陷：空参数对象不回落到默认值**：`validate_params(entry, {})` 抛「缺少参数」，因为只有 `None` 才用 defaults。修复为 `{}` 与 `None` 都使用**注册默认值**（默认值来自受控定义，不是客户端输入）。
5. **测试断言过宽**：`"code" not in json.dumps(payload)` 被 `license_code` 误触发。改为递归**键名**检查（code/script/html/url），并保留「无 steps 字段」断言。
6. **A5 静态扫描误伤自身**：扫描包含 spec 文件，命中 `vi.importActual`。修复为只扫运行时代码。
7. **ruff format**：`animation_router.py` 需重排 → 用项目锁定的 uv ruff 修正。
