## 5. 失败与修复（真实缺陷，证据保留）

1. **章节切换测试 404**：夹具只有 ch01(PRIMARY_LOWER)/ch02(JUNIOR)，同一学生无法在同学段切换章节。修复：测试内合成第三个 PRIMARY_LOWER 章节（新 release 的 ch03），不修改既有夹具语料。
2. **MissingGreenlet（测试侧）**：`content_session.rollback()` 在 SQLAlchemy 2.0 不会过期未修改实例，断言读到旧值。修复：断言查询加 `populate_existing=True`，并在 rollback 前抓住 `session_id/user_id`。
3. **MissingGreenlet（实现侧）**：`start_event_run` 命中幂等键时 `db.rollback()` 使 `LessonSession` 失效并释放行锁，`_phase_payload` 读 `session.policy_snapshot_id` 触发同步 IO。修复：去掉该 rollback，改为不失效事务的查询（锁保持到 commit）。
4. **暂停可被绕过**：迁移表允许 PAUSED 下推进阶段。修复：`resolve_event` 在 PAUSED 只允许 RESUME/RESUME_FROM_PAUSE（新增断言：暂停中 CHECK_CORRECT → 409）。
5. **开场卡片在完成后消失（浏览器实测）**：SSE 终止后前端 `refreshPhase` 用 `GET /phase`（不带 run）覆盖为 null，老师的话不可见。修复：`GET /phase` 不带 run 时保留最后已知 run，并新增 `getSession` 读取已保存的老师卡片（刷新后仍在）。证据：`T14-e2e-debug-run-disappears.log`（t=3s 元素消失）与修复后 14 passed。
6. **首次浏览器断言时机**：QUEUED 阶段没有 fixture 绑定（`fixture` 仅在夹具执行后为真），断言过早。修复：等待 run 终态再断言夹具标注。
7. **e2e 全量 3 例失败（环境）**：缺少 `E2E_STUDENT_B_*` 环境变量导致登录 422，与本卡代码无关；补合成 B 账号后 14 passed。
