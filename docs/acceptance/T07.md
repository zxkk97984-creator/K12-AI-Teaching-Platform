## 5. 首次失败与修复（保留记录）

1. **浏览器缺陷（测试捕获）**：首轮 Playwright 在 390px 断言“章节”按钮可见失败——`<1024px` 时章节栏被隐藏，而唯一的开合按钮就在栏内，窄屏无法打开章节导航。修复：把开合按钮移到始终可见的工具栏，并通过 `aria-controls` 关联章节栏；桌面收起时不再留空列。新增窄屏“打开→可见→收起→画布仍可见”断言。
2. **人工打开截图后发现的两个缺陷**（该轮 Playwright 4/4 通过，说明自动化不足以替代看图）：
   - ≥1024px 仍显示“学习内容/教师/当前活动”分段切换，而桌面三区已同时可见 → 控件无可见效果：改为 `@media (min-width:1024px)` 隐藏；
   - 主导航已有“设置”，账号区又重复同名链接 → 删除重复项。
   修复前截图保留在 `docs/design/screenshots/inspection-before-fix/`。
3. 实现过程中的类型检查失败：标签页方向键处理把索引映射写成了 `Record<string, number>` 的取值 → `TS2322/TS2538`；改为先声明映射再取值。未放宽类型或断言。
4. 组件测试两处断言与真实文案不一致（可访问名“教师”而非“教师区”、学段串空格、`模拟回复` 出现在“不显示模拟回复”这句否定文案中被误判）：修正的是**测试断言**以匹配真实渲染与语义，产品文案与可访问性未削弱；同时把教师区断言改为检查 `data-state="disabled"`、无 `article`/`log` 角色、无“老师：/Tutor：/正在生成…”。
