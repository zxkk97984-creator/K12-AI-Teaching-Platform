快速入门

欢迎使用 Knodo！本指南将帮助您在 5 分钟内了解产品核心功能，快速开始使用。

什么是 Knodo？

Knodo 是一个 AI 驱动的先进生产力平台，旨在帮助团队更高效地完成知识工作。通过整合 AI 助手、知识库管理和团队协作功能，Knodo 让您能够：

  • 🤖 与 AI 助手进行智能对话，获取专业建议和帮助
  • 📚 集中管理团队知识，支持文档版本控制
  • 👥 组建 AI Agent 团队，自动化处理复杂任务
  • 📋 任务管理，任务可委派给 Agent 执行

核心概念

在开始之前，了解以下核心概念会帮助您更好地使用 Knodo：

概念说明
组织您的团队或公司的顶层容器，用于管理成员和计费
工作空间组织内的项目单元，包含知识库、AI 配置和协作设置
知识库工作空间中的文档仓库，支持 Git 版本控制
AI Agent具有特定能力的 AI 助手，可组建团队协同工作
任务可委派给 AI Agent 执行的工作单元，支持定时调度和执行状态追踪

快速开始步骤

1. 注册并登录

访问 Knodo 官网，点击"申请内测"获取使用资格。收到邀请后，使用邀请码完成注册。

2. 创建或加入组织

完成注册登录后，系统会引导您创建或加入组织。组织是团队协作的基础单元，所有功能都需要在组织内使用。

方式一：创建新组织

适合团队负责人或需要独立使用的场景：

  1. 在组织引导页点击"创建组织"
  2. 输入组织名称（如"我的团队"）
  3. 点击创建，系统自动设置您为管理员
  4. 创建完成后，您可以邀请其他成员加入

方式二：加入已有组织

适合受邀加入团队的场景：

通过邀请链接加入

  1. 管理员分享邀请链接给您（格式：https://your-domain.com/org/join?token=xxx）
  2. 点击链接，系统自动跳转到组织引导页
  3. Token 自动填充，显示组织名称和成员数预览
  4. 点击"加入组织"即可完成加入

手动输入邀请 Token

如果您只收到了 token 字符串（而非完整链接）：

  1. 在组织引导页点击"加入组织" Tab
  2. 粘贴邀请 token（格式：xxx-xxx-xxx）
  3. 系统会验证 token 并显示组织信息
  4. 点击"加入组织"完成加入

通过邮箱邀请加入

  1. 收到邀请邮件后，点击邮件中的链接
  2. 完成登录后自动加入组织

注意事项

  • 每个用户必须至少加入一个组织才能使用 Knodo
  • 您可以同时加入多个组织，并在它们之间切换
  • 钉钉、飞书、企微用户首次登录时，如果企业已在系统中，会自动加入对应组织

3. 创建第一个工作空间

首次登录完成组织设置后，系统会自动进入 AI 引导工作空间。在这个工作空间中，AI 助手会通过对话了解你的需求，帮你配置工作空间名称和工作指引。

你也可以跳过引导，手动创建工作空间：

  • 从模板创建（推荐）：选择预设模板快速开始，自动配置场景视图和快速指令
  • AI 创建：让 AI 通过对话了解你的需求并自动完成设置

4. 开始与 AI 对话

进入工作空间后，在对话界面输入您的问题或需求，AI 助手会为您提供帮助。

示例对话： 您：帮我分析一下这份报告的要点 AI：好的，请上传或粘贴报告内容，我会为您提取关键信息...

5. 探索更多功能

  • 上传文档到知识库，让 AI 基于您的资料回答问题
  • 配置快捷命令，提高常用操作的效率
  • 尝试语音输入，解放双手
