- 不把旧 K12 或 CareerMate 整仓复制进新项目，也不把旧 Next.js/SQLite/Prisma 技术迁入新平台。
- 不实现第二套通用 Agent 执行循环、自研向量 RAG、隐藏直连 LLM 主链路或原生多 Agent 编排。
- 不把 Knodo 文档中的示例字段直接当作已登录生产契约；未知 wire 字段保持 UNKNOWN。
- 不在 R1 开放真实 K12 学生数据，除非 `G_K12_TERMS` 由平台/赛方给出依据。
- 不用本地 fixture 冒充真实 Knodo、真实 runner 或人工审校。
- 不建立家长端、排行榜、服务网格、Kubernetes、MinIO/Redis占位基础设施。
- 不把桌宠、雪碧图或按钮动效计为教学动画。
- 不把绘本塞进 R1；它保持 O01 可选增强。
- 不删除旧仓库能力或用户未跟踪资料，不运行旧 seed/start/test，不自动 commit/push。
